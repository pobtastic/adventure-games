AAA2: Event: Close The Hole
Writes the hole script and then says the hole vanishes. An object record at C2CB calls this. Reached through the action list of $0B - "Mountains Side Door" for action 00, dispatched by TriggerAction.
Event_CloseTheHole AAA2 CALL Turn_GateTheMessage Call Turn_GateTheMessage to let the message through or hold it back.
AAA5 LD A,$06 Write 06 to *CAC4.
AAA7 LD ($CAC4),A
AAAA LD HL,$C2BC Point HL at C2BC.
AAAD SET 0,(HL) Mark that object locked.
AAAF RES 7,(HL) Mark that object not visible.
AAB1 JR Event_TheHoleVanishes_PrintTheVanishing Jump back to Event_TheHoleVanishes_PrintTheVanishing to print "the hole vanish(s|d|ing|es)".
