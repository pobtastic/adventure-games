A4F5: Event: What's This
Prints "what's this ?" through Response_YouSay. A character script calls this from C8C9.
If the message is held back, "what's this ?" is not printed.
Event_WhatsThis A4F5 CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, "what's this ?" is not printed.
A4F8 LD HL,$B04B Point HL at "what's this ?".
A4FB JP Response_YouSay Jump back to Response_YouSay to print "what's this ?".
