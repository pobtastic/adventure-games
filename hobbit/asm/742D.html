742D: Message: Code 13, The Stacked Object Is Or Are
Message code 13. Does what code 11 at Message_PrintTheObjectIsOrAre does, but for the object id the caller pushed rather than the current object. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheStackedObjectIsOrAre 742D POP DE Take the object id the caller pushed into A, keeping the two return addresses, and jump back to Message_PrintTheObjectIsOrAre_0.
