73A3: Message: Code 06, Print The Current Character
Message code 06. Prints the name of the character whose turn it is. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintWhoseTurn 73A3 XOR A Write 00 to B703.
73A4 LD ($B703),A
This entry point is used by the routine at Inglish_DescribeTheAction.
Message_PrintWhoseTurn_0 73A7 LD A,($B6EA) Read the character whose turn it is.
73AA CALL Message_PrintTheFallbackToken Call Message_PrintTheFallbackToken to print the fallback token.
73AD XOR A Finish this control code with zero.
