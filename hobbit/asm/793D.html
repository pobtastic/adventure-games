793D: Grammar Workspace
Slots the grammar fills while a clause is matched. Inglish_ClearTheMatchBuffer clears the first 11 bytes. Nothing executes these bytes. Read by Inglish_ClearTheMatchBuffer, Inglish_ScoreTheCurrentAction, Inglish_ResolveTheFirstNoun, Inglish_NoteTheFirstNoun, Inglish_NoteTheSecondNoun, Inglish_TestTheScratchBits, Inglish_BuildTheActionSentence, Inglish_SaveTheClauseWindow, Inglish_ScoreTheSwappedClause, Inglish_FindTheFirstNoun, Inglish_RunTheFirstNounTest, Inglish_FindTheSecondNoun, Inglish_RunTheSecondNounTest, Inglish_CopyTheParserSlot and Inglish_PlantJumpRelativeIfNonZero. Read by Inglish_ScoreTheSwappedClause, Inglish_RunTheFirstNounTest and Inglish_CopyTheParserSlot.
793D DEFB $00 First byte of the match buffer. Inglish_ClearTheMatchBuffer blanks this and the next 10 bytes.
793E DEFB $00 Second byte of the match buffer.
793F DEFB $00 Third byte of the match buffer. The matcher tests it for zero.
7940 DEFB $00 Grammar marker. Compared with 01 while a clause is scored.
7941 DEFB $00 Second grammar marker, tested beside 7940.
7942 DEFB $00,$00,$00,$00,$00,$00 First copy window. The front word is read with 7D86, and 7B19 points DE here.
7948 DEFB $00,$00,$00,$00,$00,$00 Second copy window. 7B26 points DE here and 7DB7 reads the first byte.
794E DEFB $00,$00 Object pointer saved from IX.
7950 DEFB $00,$00 Other object pointer saved from IX.
7952 DEFB $00 Phrase byte copied into B71C.
7953 DEFB $00 Flag derived from the phrase byte.
7954 DEFB $00 Grammar count. Inglish_CopyTheParserSlot_ReadTheGrammarCount reads it.
7955 DEFB $00 Second grammar count. 7DB4 reads it.
7956 DEFB $00 Copy of the grammar marker.
7957 DEFB $00 Copy of the second grammar marker.
7958 DEFB $00,$00 Text pointer saved from HL.
795A DEFB $00,$00 Text pointer swapped with 795C.
795C DEFB $00,$00 The other pointer swapped with 795A.
795E DEFB $00,$00 Action entry saved from IX at the end of a match.
