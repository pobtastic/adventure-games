9F25: Exits: Find The Exit Through An Object
Used by the routines at Action_CarryOnWithTheObject, Action_LeaveIfTheWayIsOpen, ActionUntie and Event_TheBarrel.
Searches the exit list for an exit whose via byte (offset 01) matches the object id in A (ExitsFindTheExitThroughAnObject_0 entry point). Returns with IX at the exit, or with A=FF and the zero flag set at the end of the list.
ExitsFindTheExitThroughAnObject 9F25 LD A,($B6E8) Read *CurrentObject.
This entry point is used by the routines at Action_Unlock and Event_TheDeepBog.
ExitsFindTheExitThroughAnObject_0 9F28 PUSH AF Search on the via byte (offset 01).
9F29 LD A,$01
9F2B JR ExitsFindTheExitToALocation_PatchTheOffset Jump to ExitsFindTheExitToALocation_PatchTheOffset to search on that offset.
