8B22: Print: ZX Printer
Used by the routine at PrintWriteACharacterToTheScreen.
Copies eight pixel rows of the text line at 5020 to the ZX printer through port FB when the printer-on flag at B6F2 is set.
ZXPrinter 8B22 LD A,($B6F2) Read the printer-on flag at B6F2.
8B25 AND A Return if the printer is off.
8B26 RET Z
8B27 PUSH HL Save the text pointer. The printer row count starts at 01.
8B28 PUSH DE
8B29 PUSH BC
8B2A LD D,$01
8B2C LD HL,$5020 Point HL at the text line.
8B2F XOR A Take zero for the first printer byte.
8B30 LD E,A Clear the marker's low byte.
ZXPrinter_WriteAByteToThePrinter 8B31 OUT ($FB),A Write a byte to the printer.
ZXPrinter_Loop 8B33 IN A,($FB) Read the printer port FB.
8B35 ADD A,A Double the printer status.
8B36 JP M,ZXPrinter_RestoreAndReturn Jump to ZXPrinter_RestoreAndReturn if bit 6 of the printer port is set (no printer attached).
8B39 JR NC,ZXPrinter_Loop Jump back to ZXPrinter_Loop while bit 7 of the printer port is clear.

8B3C PUSH DE
8B3D LD A,D
8B3E CP $02 Compare the printer row count with 02.
8B40 SBC A,A Make A FF when that row count was below 02, and zero otherwise.

8B43 AND E
8B44 LD D,A

8B4A RLC C Rotate the next source bit into carry.
8B4C RRA Shift that bit into the byte for the printer.
8B4D LD H,A Remember the byte built so far.
