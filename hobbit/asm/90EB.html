90EB: Action: Inventory
Lists what the player is carrying. Reached through the action table at ActionTable, dispatched by Turn_RunTheHandlerIfPresent.
Action_Inventory 90EB CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, the inventory is not listed.
90EE LD HL,$ADF6 Point at the message "You are carrying[0x15]" (ADF6).
90F1 CALL PrintMessage Call PrintMessage to print message.
90F4 LD A,($B6EA) Read *CurrentCharacter.
Count the objects being held.
90F7 CALL ObjectCount Call ObjectCount to count the visible objects.
90FA AND A See whether nothing is held.
90FB LD HL,$B33B Point at the message "{6} nothing" (B33B).
90FE JP Z,PrintMessage Jump to PrintMessage to print it if nothing is held.
9101 LD A,($B6EA) Read the character whose turn it is.
9104 LD IX,($B70C) Use the record of the character whose turn it is.
9108 LD B,(IX+$10) Read this character's location.
910B JP Message_ListWithASeparator Jump to Message_ListWithASeparator to list what is being carried.
