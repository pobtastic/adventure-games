969A: Turn: Wait For A Key
Used by the routine at YouSeeStart.
Waits until a key is pressed, then sets the border to white.
This is the same key wait as Normal_AnyKey, but it sets the border to white before returning.
Turn_WaitForAKey 969A XOR A Read from the keyboard port.
969B IN A,($FE)
969D AND %00011111 Keep bits 0-4, one for each key in the half-row. XOR A then IN A,(FE) reads every half-row at once, and a pressed key reads as a reset bit.
969F CP $1F Loop back to Turn_WaitForAKey until any key has been pressed.
96A1 JR Z,Turn_WaitForAKey
96A3 LD A,$07 Set the border to white.
96A5 OUT ($FE),A
96A7 RET Return.
