7EFF: Inglish: Find This Character's Slot
Used by the routines at Inglish_KeepTheCharacterSlot and Inglish_SaveTheClauseAndAct.
Finds this character's slot among the eight slots at B738. Each slot is 19 bytes, and the slot id is whose turn it is.
Inglish_FindThisCharacterSlot 7EFF LD HL,$B738 Point at the first character slot at B738.
7F02 LD DE,$0019 Each character slot at B738 is 19 bytes.
7F05 LD A,($B6EA) Read *CurrentCharacter.
7F08 LD B,$08 Count 08 passes.
Inglish_FindThisCharacterSlot_TestThisSlot 7F0A CP (HL) Return if the character whose turn it is is this character slot.
7F0B RET Z
7F0C ADD HL,DE Step to the next 19-byte character slot.
7F0D DJNZ Inglish_FindThisCharacterSlot_TestThisSlot Loop back to Inglish_FindThisCharacterSlot_TestThisSlot until 08 runs out.
7F0F RET Return.
