73E0: Message: Code 0B, Print Text At A Signed Offset
Message code 0B. Prints text at a signed offset from the message pointer. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintAtASignedOffset 73E0 INC IX Step to the next character of the message.
73E2 PUSH IX Copy the text pointer, leaving it on the stack.
73E4 POP HL
73E5 PUSH HL
73E6 LD E,(IX+$00) Jump to Message_PrintAtASignedOffset_AddTheOffset if bit 7 of the next character of the message is clear.
73E9 LD D,$00
73EB BIT 7,E
73ED JR Z,Message_PrintAtASignedOffset_AddTheOffset
73EF LD D,$FF Sign-extend the stacked offset, so FF subtracts it.
Message_PrintAtASignedOffset_AddTheOffset 73F1 ADD HL,DE Add the signed offset to the text pointer.
73F2 CALL PrintMessage_Body Call PrintMessage_Body to print message.
73F5 POP IX Finish this control code with zero.
73F7 XOR A
73F8 RET Return.
