7AD8: Inglish: Test The Scratch Bits
Used by the routines at Inglish_ResolveTheFirstNoun and Inglish_CopyTheParserSlot.
Tests bits 0, 1 and 2 of the phrase scratch byte and the second match buffer, and reports no match when bit 1 is set.
Inglish_TestTheScratchBits 7AD8 LD A,($B71D) Read *B71D.
7ADB BIT 2,A Return if bit 2 of the phrase scratch byte is clear.
7ADD RET Z
7ADE LD HL,$793E Return if bit 0 of the second match buffer is set.
7AE1 BIT 0,(HL)
7AE3 RET NZ
7AE4 BIT 1,A Jump to Inglish_TestTheScratchBits_ReturnZero if bit 1 of the phrase scratch byte is set.
7AE6 JR NZ,Inglish_TestTheScratchBits_ReturnZero
7AE8 OR $01 Clear the zero flag.
7AEA RET Return.
Inglish_TestTheScratchBits_ReturnZero 7AEB XOR A Return zero from the scratch-bit test.
7AEC RET Return.
