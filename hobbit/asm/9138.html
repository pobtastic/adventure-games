9138: Action: Close
Used by the routine at Event_TheBarrel.
Closes the current object (clears bit 5 of its attributes). An object that is not open is named with message 05. Reached through the action lists of $01 - "Heavy Rock Door", $05 - "Round Green Door", $06 - "Small Insignificant Crack", $08 - "Red Door", $0A - "Goblins Back Door", $0B - "Mountains Side Door", $11 - "Goblins Door", $13 - "Barrel", $20 - "Heavy Curtain", $21 - "Large Cupboard" and $25 - "Wooden Chest" for action 0C, dispatched by TriggerAction.

913C CALL Event_TestTheOpenFlag Call Event_TestTheOpenFlag to test whether the object is open.
913F JP Z,Message_NameFromThisRecord Jump to Message_NameFromThisRecord if the object is not open.
If the message is held back, the object stays open.
9142 CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, the object stays open.
