8D25: Action: Stop If The Object Is Fixed
Used by the routines at Action_AddTheObjectMass, Action_RollAgainstTen and Action_Examine.
Stops the verb when the object is fixed or a fluid, and says that will not work.
Action_StopIfTheObjectIsFixed 8D25 CALL Action_RollAgainstTen_0 Call Action_RollAgainstTen_0 to point at the current object and see whether its copy count is 01.
8D28 JR NZ,Action_StopIfTheObjectIsFixed_SayThatWillNotWork Jump to Action_StopIfTheObjectIsFixed_SayThatWillNotWork if the copy count is not 01.
8D2A BIT 1,(IX+$07) Return if the object is not a fluid.
8D2E RET Z
Action_StopIfTheObjectIsFixed_SayThatWillNotWork 8D2F POP HL Jump to ResponseThatWillNotWork to say that will not work.
8D30 JP ResponseThatWillNotWork
