7376: Message: Code 01, The Stacked Token
Message code 01. Takes the token the caller pushed into DE and returns with the zero flag clear, so 733D prints that token. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheStackedToken 7376 POP DE Drop the dispatcher return and restore the caller's token from the stack into HL.
7377 POP HL
7378 EX (SP),HL
7379 PUSH DE Put the dispatcher return back and move the token into DE.
737A EX DE,HL
737B OR $01 Clear the zero flag so the token is printed.
737D RET Return.
