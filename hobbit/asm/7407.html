7407: Message: Code 0E, Object Pronoun
Message code 0E. Prints the pronoun for the current object. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheObjectPronoun 7407 LD A,($B6E8) Read the current object.
