C7C0: Event: Elvenkings Cellar
Runs this place's special event when a character's script reaches it. Reached through the event table at C78E, dispatched by Action_Direction.
EventElvenkingsCellar C7C0 LD A,$03 Write 03 to CAC4.
C7C2 LD ($CAC4),A
C7C5 LD HL,$C13A Point HL at the attributes of $3C - "Red Golden Dragon".
C7C8 BIT 3,(HL) Jump to EventElvenkingsCellar_Skip if "Red Golden Dragon" is "broken" (bit 3 is set).
C7CA JR NZ,EventElvenkingsCellar_Skip
C7CC LD A,$3C Write 3C to CB03.
C7CE LD ($CB03),A
EventElvenkingsCellar_Skip C7D1 LD HL,$C4CA Point HL at the attributes of $46 - "Bard".
C7D4 BIT 3,(HL) Return if the "Bard" is "broken" (bit 3 is set).
C7D6 RET NZ
C7D7 LD A,$46 Write 46 to CAFC.
C7D9 LD ($CAFC),A
C7DC RET Return.
