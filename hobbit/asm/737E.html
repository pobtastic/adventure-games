737E: Message: Code 02, Step By A Signed Byte
Message code 02. Steps the message pointer by a signed byte. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_StepByASignedByte 737E LD E,(IX+$01) Jump to Message_StepByASignedByte_ApplyTheOffset if bit 7 of the message byte at offset 1 is clear.
7381 LD D,$00
7383 BIT 7,E
7385 JR Z,Message_StepByASignedByte_ApplyTheOffset
7387 LD D,$FF The offset is negative, so the high byte is FF.
Message_StepByASignedByte_ApplyTheOffset 7389 ADD IX,DE Step the message pointer by the signed byte.
Codes 05, 0A, 0F and 12 come straight here through the control-code table at PrintTable and do nothing.
Message_StepByASignedByte_FinishOrIgnoreTheCode 738B XOR A Finish this control code with zero.
738C RET Return.
