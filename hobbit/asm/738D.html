738D: Message: Code 03, The Saved Token
Message code 03. Returns the token at B6FC, the weapon name, with the zero flag clear so 733D prints it. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheSavedToken 738D LD DE,($B6FC) Read the saved token at B6FC.
7391 OR $01 Clear the zero flag so the saved token is printed.
7393 RET Return.
