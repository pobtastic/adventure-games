9F82: Get Object First Location
Used by the routines at Turn_GateTheMessage, Turn_ApplyTheSavedMatch, TurnReportACharacter and Action_None.
Reads the first location an object appears in.
Input
A Object ID
Output
A FF if the object does not appear exactly once, otherwise the location where it first appears.
