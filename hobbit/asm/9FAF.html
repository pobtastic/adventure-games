9FAF: Message: List With A Separator
Used by the routines at Action_Look, Action_Inventory, ActionOpenOrClose and TurnDescribeWhatIsHere.
Lists the objects with a separator. When the count is zero the player sees "nothing".
Message_ListWithASeparator 9FAF PUSH IY Start the separator count at zero.
9FB1 PUSH DE
9FB2 PUSH BC
9FB3 LD C,$00
9FB5 LD D,$04 Four bytes of the separator list are considered.
9FB7 CALL Message_RememberTheSeparator Call Message_RememberTheSeparator to walk the objects here with the saved separator.
9FBA SUB A See whether the separator count in C is zero.
9FBB CP C Compare the separator count with zero.
9FBC LD HL,$B33B Point at the message " {6} nothing" (B33B).
9FBF CALL Z,PrintMessage Print " nothing" if no objects were listed.
9FC2 POP BC Restore BC, DE and IY from the stack.
9FC3 POP DE
9FC4 POP IY
9FC6 RET Return.
