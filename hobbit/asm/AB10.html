AB10: Event: The Web Smothers You
At location 1A, prints that the spider web is smothering you. The web record at CA94 calls this.
Event_TheWebSmothersYou AB10 LD A,($C12B) Return if the current location is not 1A.
AB13 CP $1A
AB15 RET NZ
AB16 LD HL,$B0FD Point at the message "the spider web is slowly smothering you." (B0FD).
AB19 CALL PrintMessage Call PrintMessage to print message.
AB1C JP YouAreDead Jump back to YouAreDead to end the game.
