8FD6: Action: Follow
Follows another character through the exit they took. Reached through the action table at ActionTable, dispatched by Turn_RunTheHandlerIfPresent.
Action_Follow 8FD6 LD IX,($B70C) Read *Pointer_CurrentCharacter.
8FDA LD B,(IX+$10) Read the location from the object record.
8FDD LD IX,($B708) Read *B708.
8FE1 LD A,(IX+$10) Read the location from the object record.
8FE4 CP B Jump to Action_Follow_PrintCannotFollow if both objects are in the same location.
8FE5 JR Z,Action_Follow_PrintCannotFollow
8FE7 CALL ExitsFindTheExitToALocation Call ExitsFindTheExitToALocation to find an exit whose destination is that location.
8FEA CP $FF Jump to Action_LeaveIfTheWayIsOpen_0 if an exit leads there.
8FEC JP NZ,Action_LeaveIfTheWayIsOpen_0
Action_Follow_PrintCannotFollow 8FEF LD HL,$AFE9 Point at the message "i cannot follow[0x07] from here[0x15]" (AFE9).
8FF2 JP PrintMessage Jump back to PrintMessage to print "i cannot follow[0x07] from here".
