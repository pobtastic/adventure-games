A541: Action: Climb Out
Climbs out of the container the character is in. Reached through the action table at ActionTable, dispatched by Turn_RunTheHandlerIfPresent.
ActionClimbOut A541 LD IY,($B70C) Read the record of the character whose turn it is.
A545 LD A,($B6E8) Read the current object.
A548 CP (IY+$01) Jump to ResponseThatWillNotWork if the character is not inside the current object.
A54B JP NZ,ResponseThatWillNotWork
A54E CALL LocateObject Call LocateObject to locate object.
A551 CALL Event_TestTheOpenFlag Call Event_TestTheOpenFlag to test whether the object is open.
A554 JP Z,Message_NameFromThisRecord Jump back to Message_NameFromThisRecord if the object is not open.
A557 CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, the character does not climb out.
A55A LD (IY+$01),$FF Mark where this object is as unset.
A55E RET Return.
