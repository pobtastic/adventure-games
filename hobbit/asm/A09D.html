A09D: Message: Exits For This Location
Used by the routines at Action_Look and TableListWhatIsHere.
Prints the exit messages for this location from the list at AFCA, indexed by the object's second flag.
Message_ExitsForThisLocation A09D LD HL,$AFCA Point HL at AFCA.
A0A0 LD A,(IX+$04) Read the second flag from the object record.
A0A3 RLCA Shift the object's second flag and keep the middle bits.
A0A4 RLCA
A0A5 AND $3C
A0A7 LD E,A
A0A8 LD D,$00 The message offset's high byte is zero.
A0AA ADD HL,DE Add the exit index to the message list.
A0AB JP PrintMessage Jump back to PrintMessage to print this exit's message.
