7B78: Inglish: Split The Clause Flags
Used by the routines at Inglish_ScoreTheCurrentAction and Inglish_BuildTheActionSentence.
Splits the clause flags into the noun-print flag, the second-noun flag and the bytes kept for the match.
Inglish_SplitTheClauseFlags 7B78 LD A,($B71E) Read *B71E.
7B7B AND $40 Keep only bit 6.
7B7D LD ($B711),A Store the result at B711.
7B80 LD A,($B71D) Read *B71D.
7B83 LD B,A Copy the result into B.
7B84 AND $01 Keep only bit 0.
7B86 LD ($B70F),A Store the result at B70F.
7B89 LD A,B Use the phrase scratch byte again.
7B8A AND $80 Keep only bit 7.
7B8C JR Z,Inglish_SplitTheClauseFlags_StoreTheNounPrintFlag Jump to Inglish_SplitTheClauseFlags_StoreTheNounPrintFlag if bit 7 of the phrase scratch byte is clear.
7B8E LD A,$01 Set the noun-print flag.
Inglish_SplitTheClauseFlags_StoreTheNounPrintFlag 7B90 LD ($B6FE),A Update *B6FE.
7B93 LD A,B Use the phrase scratch byte again.
7B94 AND $40 Keep only bit 6.
7B96 JR Z,Inglish_SplitTheClauseFlags_StoreTheSecondNounFlag Jump to Inglish_SplitTheClauseFlags_StoreTheSecondNounFlag if bit 6 of the phrase scratch byte is clear.
7B98 LD A,$01 Set the second-noun flag.
Inglish_SplitTheClauseFlags_StoreTheSecondNounFlag 7B9A LD ($B6FF),A Update *B6FF.
7B9D RET Return.
