A164: Message: Name From The Other Record
Used by the routines at Action_RollAgainstTen, Action_AddToThePlayersStrength, Action_Lock and Action_Unlock.
Reads the name token from the other record and joins the name printer.
Message_NameFromTheOtherRecord A164 LD L,(IY+$08) Read the name token from IY.
A167 LD H,(IY+$09) Read the name token's high byte from IY.
A16A JR Message_NameFromThisRecord_ChooseTheNameTable Jump to Message_NameFromThisRecord_ChooseTheNameTable to save the address and B020.
