A49C: Goblin Capture Table
Six entries of 06 bytes. Read by ActionGoblinCapture_Loop when a goblin captures an object. Each is a goblin id, the address that stores this goblin's id, the location the object is moved to, and name bytes 0A and 0B.
ActionGoblinCapture_CaptureTable A49C DEFB $3D,$18,$CB,$0F,$6A,$04 $3D - "Nasty Goblin" stores this goblin's id at CB18 and moves the object to 0F.
A4A2 DEFB $45,$1F,$CB,$3A,$37,$03 $45 - "Hideous Goblin" stores this goblin's id at CB1F and moves the object to 3A.
A4A8 DEFB $49,$2D,$CB,$12,$61,$03 $49 - "Horrible Goblin" stores this goblin's id at CB2D and moves the object to 12.
A4AE DEFB $4A,$34,$CB,$38,$34,$04 $4A - "Mean Goblin" stores this goblin's id at CB34 and moves the object to 38.
A4B4 DEFB $4B,$26,$CB,$40,$41,$07 $4B - "Vicious Goblin" stores this goblin's id at CB26 and moves the object to 40.
A4BA DEFB $4C,$3B,$CB,$10,$B6,$01 $4C - "Disgusting Goblin" stores this goblin's id at CB3B and moves the object to 10.
