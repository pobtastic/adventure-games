A1F9: Action: Read The Object's Lock Flag
Used by the routines at ActionOpenOrClose and Action_Lock.
Reads the current object's lock flag. A locked object returns 80; otherwise its attributes are tested.
Action_ReadTheObjectLockFlag A1F9 LD IX,($B708) Read *B708.
A1FD BIT 0,(IX+$07) Take 80, and return if the object is locked.
A201 LD A,$80
A203 RET NZ
This entry point is used by the routine at Action_Unlock.
Action_ReadTheObjectLockFlag_0 A204 BIT 5,(IX+$07) Test whether the object is open.
A208 LD A,$85 Return 85, the message code for an open object.
A20A RET Return.
