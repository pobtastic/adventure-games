AAC7: Event: The Lake Or The River
Used by the routines at Event_OpenTheMagicDoor and Event_CloseTheMagicDoor.
Prints the lake or the river message when the current location is 1E or 1C. Any other location returns at once.
Test the flag.
Event_TheLakeOrTheRiver AAC7 LD A,($C12B) Jump to PrintMessage if *C12B is 1E.
AACA CP $1E
AACC JP Z,PrintMessage
AACF CP $1C Jump back to PrintMessage if the current location is 1C.
AAD1 JP Z,PrintMessage
AAD4 RET Return.
