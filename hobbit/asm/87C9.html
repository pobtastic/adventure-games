87C9: Print: Proportional Character
Used by the routines at PrintWriteACharacterToTheScreen and ScrollLine.
Draws one character with the game's own font.
Input
A ASCII value
C Bit offset
HL Target screen location
Prints using the custom font.

87CB PUSH DE
87CC PUSH HL
Calculate font graphic address, some examples would be;

"a" $61 $308 ($61*08)+8722 8A2A
