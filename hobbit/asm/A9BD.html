A9BD: Event: Gollum's Reply
When the player started in Trolls Clearing, prints Gollum's reply. A character script in C913 calls this through the handler address at CA3C.
Event_GollumsReply A9BD LD A,($B6F5) Read *B6F5.
A9C0 CP $05 Return if where the player starts is not 05.
A9C2 RET NZ
If the message is held back, Gollum's reply is not printed.
A9C3 CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, Gollum's reply is not printed.
A9C6 LD A,($B6EA) Read *CurrentCharacter.
A9C9 LD HL,$B238 Jump to Event_GollumsReply_PrintGollumReply if the character whose turn it is is 47.
A9CC CP $47
A9CE JR Z,Event_GollumsReply_PrintGollumReply
A9D0 LD HL,$B24C Point HL at B24C.
Event_GollumsReply_PrintGollumReply A9D3 JP Response_YouSay Jump back to Response_YouSay to print Gollum's reply.
