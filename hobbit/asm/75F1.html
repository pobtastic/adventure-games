75F1: Inglish: Test The Conjunction Count
Used by the routines at InglishMatchOneWord, InglishRestoreTheMatch and Inglish_AskWhat.
Reads the conjunction count at B71B and returns with the zero flag set when the clause has no conjunction left.
Inglish_TestTheConjunctionCount 75F1 LD A,($B71B) Read *B71B.
75F4 AND A See whether the conjunction count is zero.
75F5 RET Return.
