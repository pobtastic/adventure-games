73BD: Message: Code 08, Print A Backspace
Message code 08. Prints a backspace. The dispatcher leaves 08 in A, and nothing else jumps here. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Print a backspace.
Message_PrintABackspace 73BD CALL Print_Character Call Print_Character to print the backspace already in A.
73C0 XOR A Finish this control code with zero.
73C1 RET Return.
