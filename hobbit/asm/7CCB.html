7CCB: Inglish: Find The First Noun
Used by the routine at Inglish_ResolveTheFirstNoun.
Finds the first noun. When the noun-print flag at B6FE is 01 it uses the place-by-exit test at ExitsFindTheExitToANamedPlace; otherwise it uses the object test at ConditionSamePlaceAsThePlayer, which looks in the same place as the player. The record found is kept in the saved object pointer at 794E.
Inglish_FindTheFirstNoun 7CCB PUSH IY Use the saved object pointer as the record being walked.

7CD5 JR Z,Inglish_FindTheFirstNoun_PointAtTheNounTest
7CD7 LD IY,$9DD9 Point IY at ConditionSamePlaceAsThePlayer to use as the noun test.
