73D6: Message: Name By The Indirect Pointer
Used by the routines at Message_PrintTheSecondNoun and Message_PrintTheFallbackToken.
Prints the current object's name. It finds the object record and hands the saved name to the printer, then returns with the text pointer restored. The message code 09 handler at Message_PrintTheSecondNoun jumps here, and Message_PrintTheFallbackToken loops back here.
Message_NameByTheIndirectPointer 73D6 PUSH HL Call Table_AddressTheObjectName to find the address of the object's name.
73D7 CALL Table_AddressTheObjectName
This entry point is used by the routine at Message_PrintTheSecondNoun.
Message_NameByTheIndirectPointer_Print 73DA CALL Message_ApplyTheSavedName Call Message_ApplyTheSavedName to print the noun held for this name.
73DD POP HL Finish this control code with zero.
73DE XOR A
73DF RET Return.
