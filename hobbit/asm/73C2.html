73C2: Message: Code 09, Print The Second Noun
Message code 09. Prints the second noun of the command. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheSecondNoun 73C2 LD A,$01 Write 01 to *B703.
73C4 LD ($B703),A
This entry point is used by the routine at Inglish_DescribeTheAction.
Message_PrintTheSecondNoun_0 73C7 LD A,($B6FF) Read *B6FF.
73CA AND A See whether the second-noun flag is zero.
73CB LD A,($B6E9) Read the second object.
This entry point is used by the routine at Message_PrintTheObject.
Message_PrintTheSecondNoun_1 73CE JR Z,Message_NameByTheIndirectPointer Jump to Message_NameByTheIndirectPointer if the second-noun flag is zero.
73D0 PUSH HL Call Table_AddressPastTheLocation to find the address of the location's name.
