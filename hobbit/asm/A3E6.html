A3E6: Action: Capture
Captures the current creature. Reached through the action table at ActionTable, dispatched by Turn_RunTheHandlerIfPresent.
ActionCapture A3E6 LD IX,($B708) Read *B708.
A3EA LD A,(IX+$04) Read the second flag from the object record.
A3ED AND $70 Keep bits 4-6 of the flags, save IX, and point IX at the object in *Pointer_CurrentCharacter.
A3EF PUSH IX
A3F1 LD IX,($B70C)
A3F5 AND (IX+$04) Test these bits of the object's second flag.
A3F8 POP IX Restore the object record from the stack and jump to ResponseThatWillNotWork if those flag bits were set.
A3FA JP NZ,ResponseThatWillNotWork
A3FD BIT 6,(IX+$07) Jump back to ResponseThatWillNotWork if the object is not an animal.
A401 JP Z,ResponseThatWillNotWork
A404 LD A,($B6EA) Read *CurrentCharacter.
A407 LD B,$1F Use location 1F and jump to ActionCapture_TestTheLocation if this character is 40.
A409 CP $40
A40B JR Z,ActionCapture_TestTheLocation
A40D CP $42 Jump to ActionCapture_TestTheLocation if the character whose turn it is is 42.
A40F JR Z,ActionCapture_TestTheLocation
A411 LD B,$0D Use location 0D for any other character.
ActionCapture_TestTheLocation A413 LD A,($B6F6) Read *B6F6.
A416 CP B Jump back to ResponseThatWillNotWork if the script location is the location in B.
A417 JP Z,ResponseThatWillNotWork

A42E LD A,($B6E8) Read *CurrentObject.
A431 CP $00 Return if the current object is not zero.
