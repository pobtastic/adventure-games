95ED: Condition: Is The Location Lit?
Used by the routines at Inglish_DescribeTheAction, DrawingClear, Action_Direction, Turn_RunTheHandlerIfPresent, Action_None and ActionCapture.
Reports whether the current location is lit.
We're only interested if the currently processed character is the player. Return if not.
