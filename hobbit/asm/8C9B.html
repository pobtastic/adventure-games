8C9B: Action: Refuse If Not Carried
Used by the routines at Action_Putdown and Action_Unlock.
Refuses the verb when the object is not carried, and the player sees "You are not carrying it".
Test whether the object is being carried.
Action_RefuseIfNotCarried 8C9B CALL ConditionIsTheObjectCarried Call ConditionIsTheObjectCarried to test whether the object is carried.
8C9E RET C Return if the object is carried (carry set).
8C9F POP HL Point at the message "You are not carrying it[0x15]".
8CA0 LD HL,$ADF1
8CA3 JP PrintMessage Jump back to PrintMessage to print "You are not carrying it".
