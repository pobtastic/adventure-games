6CEC: Turn: Read And Tokenise The Command
Reads the player's command or replays a stored one, tokenises the words and hands them to the Inglish matcher.
TurnReadAndTokeniseTheCommand 6CEC LD A,$11 Write 11 to B716.
6CEE LD ($B716),A
6CF1 LD A,($B706) Read the replay path.
6CF4 INC A Count on from the replay path.
6CF5 JR NZ,TurnReadAndTokeniseTheCommand_SetTheLineReadFlag If A is not zero then jump to TurnReadAndTokeniseTheCommand_SetTheLineReadFlag.
6CF7 CALL Turn_ResetToThePlayer Call Turn_ResetToThePlayer to reset the turn to the player.
6CFA LD HL,$6FF2 Point at the input buffer.
TurnReadAndTokeniseTheCommand_Loop 6CFD LD A,(HL) Read the next byte of the input buffer.
Echo this character of the stored line.
6CFE CALL Print_Character_0 Call Print_Character_0 to print one character.
