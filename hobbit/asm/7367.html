7367: Message: Code 00, The Stacked Object
Message code 00. Pops the object-record pointer the caller pushed. When that pointer is not zero, Message_ApplyTheSavedName names the object. Reached through the control-code table at PrintTable, dispatched by PrintMessage.

736C POP HL
736D EX (SP),HL
736E PUSH DE Put the dispatcher return back, and call Message_ApplyTheSavedName if the object pointer is not zero.
736F LD A,H
7370 OR L
