910E: Action: Open Or Close
Used by the routines at ActionBurn, Action_OpenTheGoblinsDoor, Event_AShortReply and Event_TheBarrel.
Opens or closes the current object. Reached through the action lists of $01 - "Heavy Rock Door", $05 - "Round Green Door", $08 - "Red Door", $0A - "Goblins Back Door", $13 - "Barrel", $1E - "Trap Door", $20 - "Heavy Curtain", $21 - "Large Cupboard" and $25 - "Wooden Chest" for action 10, dispatched by TriggerAction.
ActionOpenOrClose 910E CALL Action_ReadTheObjectLockFlag Call Action_ReadTheObjectLockFlag to read the object's lock flag.
9111 JP NZ,Message_NameFromThisRecord Jump to Message_NameFromThisRecord to say so if Action_ReadTheObjectLockFlag found the object locked (80) or already open (85).
If the message is held back, the object is not opened or closed.
9114 CALL ConditionSuppressTheMessage Call ConditionSuppressTheMessage. If the message is held back, the object is not opened or closed.
This entry point is used by the routines at Action_TalkTo and ActionBurn.
