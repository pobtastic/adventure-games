7AED: Inglish: Ask Whether To Suppress
Used by the routines at InglishApplyAMatch, Inglish_ResolveTheFirstNoun, Inglish_RunTheSecondNounTest and Inglish_SaveTheClauseAndAct.
Runs the action handler if one is present and returns whether the message-suppressed flag is zero, which suppresses the sentence.
Inglish_AskWhetherToSuppress 7AED CALL Turn_RunTheHandlerIfPresent Call Turn_RunTheHandlerIfPresent to run the handler when one is present.
7AF0 LD A,($B6FB) Read the message-suppressed flag.
7AF3 AND A Return with the zero flag set when no message was held back.
7AF4 RET Return.
