8498: Load: Read The Save Block
Used by the routine at LoadGame.
Reads a save block from tape, prints the prompt at B357, and waits for a key before returning to the loader.
Load Block
LoadBlock 8498 CALL $0556 Call LD_BYTES.
849B RET C Return if the tape block loaded (carry set).
849C LD A,$01 Write 01 to WaitCountdown.
849E LD ($B701),A
84A1 LD HL,$B357 Point HL at B357.
84A4 CALL PrintMessage Call PrintMessage to print message.
LoadBlock_Loop 84A7 XOR A Read from the keyboard port.
84A8 IN A,($FE)
84AA AND %00011111 Keep bits 0-4, one for each key in the half-row. XOR A then IN A,(FE) reads every half-row at once, and a pressed key reads as a reset bit.
84AC CP $1F Loop back to LoadBlock_Loop until any key has been pressed.
84AE JR Z,LoadBlock_Loop
84B0 JP Restart Jump back to Restart to restart the game.
