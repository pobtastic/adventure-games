A5CA: Event: Test The Open Flag
Used by the routines at Action_CarryOnWithTheObject, Action_Close, Action_Examine, ActionClimbOut and EventContainersAndScripts.
Tests whether the object is open and returns 05. The zero flag is set when the object is not open. The bytes after that return belong to later events.
