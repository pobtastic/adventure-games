41117: Message: Exits For This Location
Used by the routines at Action_Look and TableListWhatIsHere.
Prints the exit messages for this location from the list at 45002, indexed by the object's second flag.
Message_ExitsForThisLocation 41117 LD HL,45002 Point HL at 45002.
41120 LD A,(IX+4) Read the second flag from the object record.
41123 RLCA Shift the object's second flag and keep the middle bits.
41124 RLCA
41125 AND 60
41127 LD E,A
41128 LD D,0 The message offset's high byte is zero.
41130 ADD HL,DE Add the exit index to the message list.
41131 JP PrintMessage Jump back to PrintMessage to print this exit's message.
