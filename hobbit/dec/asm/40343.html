40343: Condition: Count The Visible Objects
Used by the routines at Action_Inventory, ActionOpenOrClose, Action_Examine, TableListWhatIsHere and ActionTie.
Counts the visible objects at the location or container in A. A character id counts what that character holds. An object is visible when bit 7 of its attribute byte is set.
Input
A Location or container id (the character id counts objects held)
Output
A The number of objects
