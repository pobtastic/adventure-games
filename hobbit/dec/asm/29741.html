29741: Message: Code 19, The Stacked Object Is Or Are
Message code 19. Does what code 17 at Message_PrintTheObjectIsOrAre does, but for the object id the caller pushed rather than the current object. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
