32511: Inglish: Find This Character's Slot
Used by the routines at Inglish_KeepTheCharacterSlot and Inglish_SaveTheClauseAndAct.
Finds this character's slot among the eight slots at 46904. Each slot is 25 bytes, and the slot id is whose turn it is.
Inglish_FindThisCharacterSlot 32511 LD HL,46904 Point at the first character slot at 46904.
32514 LD DE,25 Each character slot at 46904 is 25 bytes.
32517 LD A,(46826) Read *CurrentCharacter.
32520 LD B,8 Count 8 passes.
Inglish_FindThisCharacterSlot_TestThisSlot 32522 CP (HL) Return if the character whose turn it is is this character slot.
32523 RET Z
32524 ADD HL,DE Step to the next 25-byte character slot.
32525 DJNZ Inglish_FindThisCharacterSlot_TestThisSlot Loop back to Inglish_FindThisCharacterSlot_TestThisSlot until 8 runs out.
32527 RET Return.
