29664: Message: Code 11, Print Text At A Signed Offset
Message code 11. Prints text at a signed offset from the message pointer. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintAtASignedOffset 29664 INC IX Step to the next character of the message.
29666 PUSH IX Copy the text pointer, leaving it on the stack.
29668 POP HL
29669 PUSH HL
29670 LD E,(IX+0) Jump to Message_PrintAtASignedOffset_AddTheOffset if bit 7 of the next character of the message is clear.
29673 LD D,0
29675 BIT 7,E
29677 JR Z,Message_PrintAtASignedOffset_AddTheOffset
29679 LD D,255 Sign-extend the stacked offset, so 255 subtracts it.
Message_PrintAtASignedOffset_AddTheOffset 29681 ADD HL,DE Add the signed offset to the text pointer.
29682 CALL PrintMessage_Body Call PrintMessage_Body to print message.
29685 POP IX Finish this control code with zero.
29687 XOR A
29688 RET Return.
