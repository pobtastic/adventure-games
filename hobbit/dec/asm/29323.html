29323: Input: Compare Two Totals
Used by the routine at Input_WaitForAKey.
Compares two 16-bit totals. Carry is set when the first is below the second. The input delay uses it to cap the next wait at 3000.
Input_CompareTwoTotals 29323 LD A,H Return at once when the high bytes differ. Carry is set when the first total is below.
