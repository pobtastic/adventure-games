29654: Message: Name By The Indirect Pointer
Used by the routines at Message_PrintTheSecondNoun and Message_PrintTheFallbackToken.
Prints the current object's name. It finds the object record and hands the saved name to the printer, then returns with the text pointer restored. The message code 9 handler at Message_PrintTheSecondNoun jumps here, and Message_PrintTheFallbackToken loops back here.
