40879: Message: List With A Separator
Used by the routines at Action_Look, Action_Inventory, ActionOpenOrClose and TurnDescribeWhatIsHere.
Lists the objects with a separator. When the count is zero the player sees "nothing".
Message_ListWithASeparator 40879 PUSH IY Start the separator count at zero.
40881 PUSH DE
40882 PUSH BC
40883 LD C,0
40885 LD D,4 Four bytes of the separator list are considered.
40887 CALL Message_RememberTheSeparator Call Message_RememberTheSeparator to walk the objects here with the saved separator.
40890 SUB A See whether the separator count in C is zero.
40891 CP C Compare the separator count with zero.
40892 LD HL,45883 Point at the message " {6} nothing" (45883).
40895 CALL Z,PrintMessage Print " nothing" if no objects were listed.
40898 POP BC Restore BC, DE and IY from the stack.
40899 POP DE
40900 POP IY
40902 RET Return.
