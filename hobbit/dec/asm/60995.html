60995: Graphics: Lower Halls
Lower Halls
Drawing commands for this location, read by Drawing. The first byte is the border colour and the second is the paper and ink. 0 ends the list. 8 followed by X and Y moves the pen. A byte with bit 7 set draws a line: bits 0-2 are the direction, and the next byte holds the length and the step, then Drawing_PlotTheSelectedPixel plots it. A byte with bit 6 set and bit 7 clear is a fill: bits 0-2 are the colour and the next two bytes are the point DrawingSetup_0 floods from. A byte with bit 5 set and bits 6 and 7 clear paints attributes: bits 0-2 are the colour, the next two bytes are an attribute address, and the following bytes run until 255. Any other byte below 32 is skipped. A dark location is drawn in black. Drawn by Drawing.
