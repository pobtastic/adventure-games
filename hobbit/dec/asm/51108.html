51108: Event: Beorns House
Runs this place's special event when a character's script reaches it. Reached through the event table at 51086, dispatched by Action_Direction.
At the start of the game, the Butler is invisible (!) and only becomes visible after entering Beorns House.
EventBeornsHouse 51108 LD HL,50231 Point HL at the attributes of 66 - "Butler".
51111 BIT 3,(HL) Return if the "Butler" is "broken" (bit 3 is set).
51113 RET NZ
51114 LD A,66 Write 66 to 51943.
51116 LD (51943),A
51119 SET 7,(HL) Set "visible" bit for "Butler".
51121 RET Return.
