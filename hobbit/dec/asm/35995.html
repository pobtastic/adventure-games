35995: Action: Refuse If Not Carried
Used by the routines at Action_Putdown and Action_Unlock.
Refuses the verb when the object is not carried, and the player sees "You are not carrying it".
Test whether the object is being carried.
Action_RefuseIfNotCarried 35995 CALL ConditionIsTheObjectCarried Call ConditionIsTheObjectCarried to test whether the object is carried.
35998 RET C Return if the object is carried (carry set).
35999 POP HL Point at the message "You are not carrying it[0x15]".
36000 LD HL,44529
36003 JP PrintMessage Jump back to PrintMessage to print "You are not carrying it".
