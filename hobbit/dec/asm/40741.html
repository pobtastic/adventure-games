40741: Exits: Find The Exit Through An Object
Used by the routines at Action_CarryOnWithTheObject, Action_LeaveIfTheWayIsOpen, ActionUntie and Event_TheBarrel.
Searches the exit list for an exit whose via byte (offset 1) matches the object id in A (ExitsFindTheExitThroughAnObject_0 entry point). Returns with IX at the exit, or with A=255 and the zero flag set at the end of the list.
