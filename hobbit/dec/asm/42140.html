42140: Goblin Capture Table
Six entries of 6 bytes. Read by ActionGoblinCapture_Loop when a goblin captures an object. Each is a goblin id, the address that stores this goblin's id, the location the object is moved to, and name bytes 10 and 11.
ActionGoblinCapture_CaptureTable 42140 DEFB 61,24,203,15,106,4 61 - "Nasty Goblin" stores this goblin's id at 51992 and moves the object to 15.
42146 DEFB 69,31,203,58,55,3 69 - "Hideous Goblin" stores this goblin's id at 51999 and moves the object to 58.
42152 DEFB 73,45,203,18,97,3 73 - "Horrible Goblin" stores this goblin's id at 52013 and moves the object to 18.
42158 DEFB 74,52,203,56,52,4 74 - "Mean Goblin" stores this goblin's id at 52020 and moves the object to 56.
42164 DEFB 75,38,203,64,65,7 75 - "Vicious Goblin" stores this goblin's id at 52006 and moves the object to 64.
42170 DEFB 76,59,203,16,182,1 76 - "Disgusting Goblin" stores this goblin's id at 52027 and moves the object to 16.
