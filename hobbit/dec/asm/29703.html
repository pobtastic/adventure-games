29703: Message: Code 14, Object Pronoun
Message code 14. Prints the pronoun for the current object. Reached through the control-code table at PrintTable, dispatched by PrintMessage.
Message_PrintTheObjectPronoun 29703 LD A,(46824) Read the current object.
29706 JR Message_PrintThePronoun_0 Jump back to Message_PrintThePronoun_0 to choose the pronoun token for this object.
