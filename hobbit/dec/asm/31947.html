31947: Inglish: Find The First Noun
Used by the routine at Inglish_ResolveTheFirstNoun.
Finds the first noun. When the noun-print flag at 46846 is 1 it uses the place-by-exit test at ExitsFindTheExitToANamedPlace; otherwise it uses the object test at ConditionSamePlaceAsThePlayer, which looks in the same place as the player.
