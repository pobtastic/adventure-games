32023: Inglish: Find The Second Noun
Used by the routine at Inglish_ResolveTheFirstNoun.
Finds the second noun the same way, storing it as the second object. When the second-noun flag at 46847 is 1 it uses the place-by-exit test at ExitsFindTheExitToANamedPlace; otherwise it uses the object test at ConditionSamePlaceAsThePlayer. The record found is kept at 31056, and bit 0 of 46877 is copied to 46863.
