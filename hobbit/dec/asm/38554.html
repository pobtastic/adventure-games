38554: Turn: Wait For A Key
Used by the routine at YouSeeStart.
Waits until a key is pressed, then sets the border to white.
This is the same key wait as Normal_AnyKey, but it sets the border to white before returning.
Turn_WaitForAKey 38554 XOR A Read from the keyboard port.
38555 IN A,(254)
38557 AND %00011111 Keep bits 0-4, one for each key in the half-row. XOR A then IN A,(254) reads every half-row at once, and a pressed key reads as a reset bit.
38559 CP 31 Loop back to Turn_WaitForAKey until any key has been pressed.
38561 JR Z,Turn_WaitForAKey
38563 LD A,7 Set the border to white.
38565 OUT (254),A
38567 RET Return.
