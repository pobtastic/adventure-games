A791: Load/ Save Buffer
SaveGame copies each configurable exit byte here before saving, and LoadTape writes those bytes back after a successful load. The copy length is *Count_ConfigurableExits. The rest of this 32 byte buffer is not read or written by those loops.
Buffer_LoadSave A791 DEFB $00 Saved exit byte 00.
A792 DEFB $00 Saved exit byte 01.
A793 DEFB $00 Saved exit byte 02.
A794 DEFB $00 Saved exit byte 03.
A795 DEFB $00 Saved exit byte 04.
A796 DEFB $00 Saved exit byte 05.
A797 DEFB $00 Saved exit byte 06.
A798 DEFB $00 Saved exit byte 07.
A799 DEFB $00 Saved exit byte 08.
A79A DEFB $00 Saved exit byte 09.
A79B DEFB $00 Saved exit byte 0A.
SaveGame and LoadTape stop after *Count_ConfigurableExits bytes (0B). Nothing reads the rest. The initial image is FE32.
