7C8D: Graphics: The Main Courtyard
The Main Courtyard
Mask bytes. Each bit stands for one screen byte. When the bit is set, Print_RoomImage writes a pixel byte from Image_MainCourtyard_Pixels; when it is clear, DE still advances but nothing is written, so those 8 pixels stay blank. Print_RoomImage starts here and skips ahead 0200 bytes to the pixel data.
