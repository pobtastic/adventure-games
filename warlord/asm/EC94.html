EC94: Process: Enter Vale Of Rhia
Process_EnterValeOfRhia EC94 LD HL,$A76D Return if bit 6 of *Flag_QuestProgress is set.
EC97 BIT 6,(HL)
EC99 RET NZ
EC9A SET 6,(HL) Set bit 6 of *HL.
EC9C LD A,$04 Call AddToScore to add 04 points to the score.
EC9E CALL AddToScore
ECA1 RET Return.
