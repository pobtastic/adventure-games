5CCB: BASIC Loader
The BASIC program "Vera Cruz" on the part 1 tape. It autostarts at line 10.
  • Line 20 loads the first CODE block at 8000: a copy of DrawPicture followed by the title card picture.
  • Line 30 draws the title card (picture 01) straight onto the screen; see Loading.
  • Line 40 prints "First Part" over it.
  • Line 60 loads the main code block at 8000.
  • Line 80 loads the code block at FB00 (see DisplayFrame).
  • Line 120 loads the game itself, which is written in BASIC.
