5CCB: BASIC Loader
The BASIC program "Vera Cruz" on the part 2 tape. It autostarts at line 10.
  • Line 20 loads the first CODE block at C350: a copy of DrawPicture followed by the title card picture.
  • Line 30 draws the title card (picture 01) straight onto the screen; see Loading.
  • Line 40 prints "Second Part" over it.
  • Lines 50-80 load the main code block at C350, then the code blocks at FB00 (see DisplayFrame), FCA0 (see ScrollWindow) and FD0E (see PrintString).
  • Line 100 loads the game itself, which is written in BASIC.
