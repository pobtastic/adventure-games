64782: Print String
Prints the BASIC string "s$" at the current print position in a 64-column font. It finds the string with the ROM routine LOOK-VARS, using the name at PrintString_VariableName, and stops with an error if it is missing. Codes below 32 go straight to RST 16; codes from 144 upwards are skipped.
