32770: Draw Picture Parameters
Parameters for DrawPicture, read and written through IY. BASIC only POKEs the picture number here; *DrawPicture_Third and *DrawPicture_Thirds are always 255 in the snapshot, so the routine takes the screen third and the number of thirds from the picture record.
The flags at DrawPicture_Flags:
Bit Relating To
0 Pixel data order (set: rows; clear: columns)
2 Set while a run of repeated bytes is being written
3 Set while the attributes are being drawn
DrawPicture_Number 32770 DEFB 1 Picture number (1 for the first picture in the list).
DrawPicture_Third 32771 DEFB 255 Screen third to start at, from 0 (top) to 2 (bottom). 255 means use the value in the picture record.
DrawPicture_Thirds 32772 DEFB 255 Number of thirds to draw, from 1 to 3. 255 means use the value in the picture record.
DrawPicture_Flags 32773 DEFB 12 Flags, copied from the picture record.
