59699: Data: Scenic Event Rooms
The rooms each scenic event moves between, as lists of room numbers ending with 255. The pointers at Table_ScenicEventRooms, set from 65169, say which list each event uses. Each turn GameEventsProcessor takes every event that is in play and not with the player, steps a random distance round its list (going back to the start at 255) and puts it in the room it lands on (Table_ScenicEventLocations).
