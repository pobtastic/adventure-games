59502: Data: Item Groups
For each object in Table_TokenItemList, in the same order: the items it may refer to, ending with 255. Numbers with bit 7 set are scenic events (Table_ScenicEventLocations): 128 is event 0 and so on. The pointers at Table_ItemGrouping say where each group starts.
Parser_CheckObjectIsHere takes an object the player named and checks each item in its group with ValidateItemPresent; if none of them is here or carried it prints "I can't see ... here." with the name from Table_ObjectNounPhrases. Many actions also point HL straight at a group and call CheckActiveScenicEvents to find out which of its items is present.
