BC70: Table: Turn-Based Event Items
A table mapping each turn-based event (by bit position in Flag_EventState) to its associated item ID.
When a turn-based event is active, its item is moved to the current room.
The events correspond to the bits as follows:
Bit Event Item ID
00 Crab 29
01 Tentacle 00
02 Drunk 00
03 Lion 00
04 Crocodile 00
05 Cannibals 00
06 Match 00
07 Wave 00
