C3FA: Handler: Put Scenic Event Into Play
Used by the routine at Action_Take.
Writes FF over the event's byte in Table_ScenicEventLocations. On the next turn GameEventsProcessor treats FF as in play but not yet in a room, and picks one from Data_ScenicEvents_Seagull.
Input
A Scenic event ID (+80)
Handler_PutScenicEventIntoPlay C3FA LD B,A Copy the scenic event ID into B.
C3FB LD C,$FF Set C to FF so the event is in play but has no room yet.
C3FD CALL Handler_UpdateObjectLocation Call Handler_UpdateObjectLocation.
C400 RET Return.
