65D2: Pause Loop
Pause for the number of frames passed by the caller.
Input
B Number of frames to wait
Pause_Loop 65D2 HALT Wait for the next frame.
65D3 DJNZ Pause_Loop Wait out the remaining frames.
65D5 RET Return.
