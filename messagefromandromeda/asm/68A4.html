68A4: Parser: Resolve Phrase
Used by the routine at GameLoop.
Walk this noun's object list from Pointer_ObjectNounPhrases and call IsObjectInCurrentRoom for each object. Return if one is in the current room or the inventory. Otherwise print "I can't see ", the noun name from Pointer_ObjectList and " here.", then set the carry flag.

BC Count left by the caller's object-list search
Output
