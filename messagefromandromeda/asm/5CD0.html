5CD0: Tape Loader
Load the screen, then the game image. The length check keeps the graphics and the code as two blocks.
Load the first block: the loading screen.
TapeLoader 5CD0 LD IX,$4000 Load the screen from tape into the display file.
5CD4 LD DE,$1B00
5CD7 CALL TapeLoading
Choose one graphics block or two.
5CDA LD HL,$7530 Jump to TapeLoader_Step2 when the pictures fit in one tape block.
5CDD LD DE,$98F4
5CE0 AND A
5CE1 SBC HL,DE
5CE3 JR NC,TapeLoader_Step2
TapeLoader_Step1 5CE5 LD IX,$61A8 Load the engine, the text and the first pictures at GameEntryPoint.
5CE9 LD DE,$7530
5CEC CALL TapeLoading
5CEF LD IX,$D6D8 Load the remaining pictures at D6D8.
5CF3 LD DE,$23C4
5CF6 CALL TapeLoading
5CF9 RET Return.
TapeLoader_Step2 5CFA LD IX,$61A8 Load the pictures and the code as one block at GameEntryPoint.
5CFE LD DE,$98F4
