65E6: Handler: Update Object Location
Used by the routines at MovePlayerToRoom, HandlerPickUpObject, ActionDrop, ActionGive, ActionCut, ActionKill, ActionOpen, ActionClose, ActionShoot, ActionWear, ActionTurn, ActionType, ActionTouch and ActionUse.
Write a new location for an object. The caller passes the object and the room, or 01 when the object is carried.
UpdateObjectLocation 65E6 BIT 7,B An ordinary object is stored in the location table.
65E8 JR Z,UpdateObjectLocation_Step1
65EA RES 7,B The scenic marker is not part of the object number.
65EC LD HL,$6224 Continue at UpdateObjectLocation_Step2 to store this scenic object's room.
65EF JR UpdateObjectLocation_Step2
UpdateObjectLocation_Step1 65F1 LD HL,$61AB The ordinary objects are kept in the location table.
UpdateObjectLocation_Step2 65F4 LD D,$00 Store the new location for this object.
65F6 LD E,B
65F7 ADD HL,DE
65F8 LD (HL),C
65F9 RET Return.
