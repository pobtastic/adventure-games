Workspace filled from Default_Table_ItemLocations by the routine at GameStart. Object locations occupy the 41 bytes at Table_ItemLocations. The current room is *CurrentRoom. Pointers to the message, exit and handler tables follow the command buffer.

Flags: Display State
Bit 0 is set when a room picture is waiting for a keypress.

One bit per entry in Table_RoomsWithImages. Handler_DisplayRoom tests and sets the bit for the current room's picture slot.

Flags: Turn-Based Event States
Holds a single byte, where each bit relates to a turn-based event. When the bit is set, HandlerTurnBasedEvents runs the matching handler from Table_TurnBasedEventHandlers.

Turn-Based Event Counters
One countdown per bit of *Flag_TurnBasedEventState.

Holds a single byte, where each set bit arms a scenic event. HandlerScenicEvents walks these bits and plants a message when the player is not already in that event's room from Table_ScenicEventLocations.
