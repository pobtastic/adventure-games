27026: Parser: Match Or Rephrase
Used by the routines at ActionLeave and ActionLand.
Return when the next token is absent or the phrase matches. Otherwise print "Please rephrase that.".
Parser_MatchOrRephrase 27026 LD A,(25234) Fetch the second word of the command.
27029 CP 255 Return if the command has no second word (255).
27031 RET Z
27032 CALL Parser_FindPhrase Call Parser_FindPhrase to look for a noun.
27035 RET NZ Return when the command names a noun.
27036 CALL ResponsePleaseRephraseThat Call ResponsePleaseRephraseThat to ask the player to rephrase the command.
27039 SCF Set the carry flag to reject the command.
27040 RET Return.
