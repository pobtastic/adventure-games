27026: Parser: Match Or Rephrase
Used by the routines at ActionLeave and ActionLand.
Allow a command with no object. Otherwise require a named noun.
Output
F The zero flag is set when there is only a verb present
F The zero flag is unset when there is at least one valid noun
F The carry flag is set when the command is malformed
The first token is the verb, so target the second token for the direct object.
