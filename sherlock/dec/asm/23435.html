23435: Tape Loader: LD_BYTES
Used by the routine at TapeLoader_Game.
Calls the ROM tape loader, shows a white border while it runs, and records success or failure in the tape load result.
Arrange the flags the ROM loader expects.
TapeLoader_LoadBytes 23435 INC D Leave D one below 255 so the block length survives the ROM loader's test.
23436 EX AF,AF' Park the header/data marker. A is 0 for a header and 255 for a data block.
23437 DEC D Put the block length back. The ROM loader rejects a length whose top byte is 255.
23438 DI Disable interrupts so the tape timing is stable.
