51647: Process Display Record
Used by the routine at ProcessObjectDisplayEntry.
HL points at a display record (flags, value, optional handler word, optional five extra bytes). Checks the record against the current object, character and graphics, runs its handler if bit 6 is set, and then either returns the address after the record (bit 7 set) or runs the code that follows it via 51812. A non-zero return means the script step succeeded.
