40919: Location Value
Stores a location reference value used in room display scripts (a 2-byte value that can be accessed as high or low byte via special parameters). Read by ProcessDisplayRecord, ProcessRoomDisplayParameter, GetScriptPointerFromTimetable, UpdateScriptPointer, ParseInput and DescribeObjectIfPresent.
