45421: Display Flag
Flag byte for display processing (bit 1 indicates objects have been processed). Read by InitialiseDisplayBuffer, SwapObjectDisplayPointers, CheckFlagAndSetDisplay_ProcessPointer, UnlinkNextDisplayRecord and SelectJumpIfNotZero.
DisplayFlag 45421 DEFB 0
45422 DEFB 0,0 Display flag word.
45424 DEFB 0 Count of passes through the primary display flag.
45425 DEFB 0 Count of passes through the secondary display flag.
