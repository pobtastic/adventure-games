45427: Display Mode Flag
Flag controlling display mode (bit 7 indicates special display mode). Read by CheckFlagAndSetDisplay, FindFirstNoun and SelectJumpIfNotZero.
DisplayModeFlag 45427 DEFB 0
45428 DEFW 0 Saved display pointer, read by InitialiseDisplayBuffer.
45430 DEFW 0 Saved display pointer, read by InitialiseDisplayBuffer.
45432 DEFB 0 Low byte of the display mode word, read by SwapObjectDisplayPointers, CheckFlagAndSetDisplayParameter, TestEndMarker, UnlinkNextDisplayRecord, SelectJumpIfNotZero, CalculateObjectPointerOffset and ReadCharacterRecordValue.
45433 DEFB 0 High byte of the display mode flag, read by CheckFlagAndSetDisplayParameter, MatchSecondNoun and SelectJumpIfNotZero.
45434 DEFB 0,0,0,0 Bytes beside the display mode word.
