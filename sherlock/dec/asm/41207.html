41207: Fetch Object Pointer From Stack
Used by the routines at FollowLinkPointer, CheckCharacterBeingProcessed, RecordResultCharacterScript, ProcessObjectPointer, DispatchCharacterScript, FindCharacterScriptEntry_StartSearch, FindCharacterSavedPointer and ProcessCharacterAttribute.
Takes the record linked just before this one, or reports that the link is empty.
Input
IX Object pointer (on stack)
Output
IX Object pointer
HL Zero if object pointer was zero, otherwise preserved
This will be restored back into HL by the end of the routine.
