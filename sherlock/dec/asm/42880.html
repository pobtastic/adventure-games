42880: Pronoun For This Character
Reads the current character and continues at PronounForThisCharacter_OtherId. A zero id returns token 2546. Any other id returns token 1044. Either result is non-zero, so the caller prints the token.
Control code 12 in the table at JumpTable_ControlCharacters.
Used by the routine at DispatchTextControlHandler.
