54248: Check Object Has Special Description
Used by the routines at CheckObjectHasSpecialDescription_Wrapper, ProcessTextTokenEntry and TakeTheFoundObject.
Reads the object's description word through CheckTokenMatchAndSetFlag and clears 42986 unless bit 6 of IY-2 is set. Then prints the tokens at IY+2 and IY+4 or only the one at IY+4 when bit 5 of IY-1 is set.
CheckObjectHasSpecialDescription 54248 PUSH AF Save the registers, then read the word at IY+0-1 into DE.
54249 PUSH DE
54250 LD D,(IY+1)
54253 LD E,(IY+0)
54256 CALL CheckTokenMatchAndSetFlag Call CheckTokenMatchAndSetFlag to test the token and set the flag.
54259 BIT 6,(IY-2) Go to CheckObjectHasSpecialDescription_Next if bit 6 of this byte is set.
54263 JR NZ,CheckObjectHasSpecialDescription_Next
54265 XOR A Clear the token match flag at 42986.
54266 LD (42986),A
CheckObjectHasSpecialDescription_Next 54269 BIT 5,(IY-1) Go to ReadScheduleField if bit 5 of this byte is set.
54273 JR NZ,ReadScheduleField
54275 JR 54294 Go on to read the high byte of the object's description token.
