53174: Find Character Script Entry
Used by the routines at MeasureCharacterDistance, DispatchCharacterScript, GetScriptPointer, GetScriptPointerFromTimetable, UpdateScriptPointer, PlaceCharacter, ReadSourceDisplayPointer, StoreActionFlags and PrintActionMessage.
Searches through the character script entry list to find an entry matching the current character ID. Returns the entry pointer if found, otherwise returns 0.
Output
IX Character script entry pointer (if found)
A 0 if not found, bit 0 set if found
FindCharacterScriptEntry 53174 LD A,(41014) Read the current character.
