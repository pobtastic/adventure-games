41191: Load Or Save The Game
Used by the routine at Game_Initialisation.
Loads the game unless the parameter is 2 which saves it instead.
Input
A 2 saves the game. Any other value loads it
LoadOrSaveGame 41191 CP 2 Go to LoadOrSaveGame_Save if it is 2.
