A7D0: Check Token Match And Set Flag
Used by the routines at ProcessTextTokenWithAttributes, CheckObjectHasSpecialDescription and CheckObjectAttributeWithFlag.
Compares the token with the text and sets the match flag.
Input
DE Token value to check
CheckTokenMatchAndSetFlag A7D0 XOR A Clear the token match flag at A7EA.
A7D1 LD ($A7EA),A
A7D4 BIT 7,D Jump ahead to PrintTokenBasedOnParameters if bit 7 of D is clear.
A7D6 JR Z,PrintTokenBasedOnParameters
A7D8 LD A,E Load 09EE and go to CheckTokenMatchAndSetFlag_Next if the low byte of the token is not EE.
A7D9 LD HL,$09EE
A7DC CP L
A7DD JR NZ,CheckTokenMatchAndSetFlag_Next
A7DF LD A,D Read the high byte of the token.
A7E0 AND %00001111 Take the dictionary page (the low nibble of the token's high byte) to compare with the 09 of token 09EE.
A7E2 CP H See whether the two values match.
A7E3 RET Z Return if they match.
CheckTokenMatchAndSetFlag_Next A7E4 LD A,$01 Write 01 to the token match flag at A7EA.
A7E6 LD ($A7EA),A
A7E9 RET Return.
