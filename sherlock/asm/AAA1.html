AAA1: Display Bytes
Bytes read while a picture is drawn. Read by HandleClassAWord and ApplySavedClause.
DisplayBytes AAA1 DEFB $00,$00 Two zero bytes read while a picture is drawn.
AAA3 DEFB $00 Display byte read with the one at AAA6, read by HandleClassAWord and ApplySavedClause.
AAA4 DEFB $00,$00 Word read as the display record, read by HandleClassAWord and ApplySavedClause.
AAA6 DEFB $00 Display byte read with the one at AAA3, read by HandleClassAWord and ApplySavedClause.
AAA7 DEFB $00 Cleared state byte, read by StartPictureModeScreenIdle and ClearCoordinateBuffer.
