A0E7: Load Or Save The Game
Used by the routine at Game_Initialisation.
Loads the game unless the parameter is 02 which saves it instead.
Input
A 02 saves the game. Any other value loads it
LoadOrSaveGame A0E7 CP $02 Go to LoadOrSaveGame_Save if it is 02.
