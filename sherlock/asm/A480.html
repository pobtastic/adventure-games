A480: Print One Decimal Digit
Used by the routine at PrintHundredsTensAndUnits.
Prints one decimal digit, suppressing leading zeros.
PrintOneDecimalDigit A480 CALL DivideBySubtraction Call DivideBySubtraction to divide HL by DE (quotient in A, remainder in HL).
A483 ADD A,$30 Turn the number into a character.
A485 DEC C Print the digit at once if an earlier digit was printed.
A486 INC C
A487 JR NZ,PrintOneDecimalDigit_0
A489 CP $30 Return when the character is the digit zero.
A48B RET Z
A48C INC C Note that a digit has been printed.
PrintOneDecimalDigit_0 A48D JP Print_Character Jump to Print_Character to print the digit.
