A684: Continue At The Next Token
Reads the next word from the text pointer at A59D and uses that address as the record pointer, then returns zero. The time-of-day entries from ContinueAtTheNextToken_SixInTheMorning return when the period matches, and otherwise skip one token from ContinueAtTheNextToken_0.
Control code 1A in the table at JumpTable_ControlCharacters.
Used by the routine at DispatchTextControlHandler.
Output
IX Address of the next word
