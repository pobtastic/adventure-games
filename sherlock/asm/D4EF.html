D4EF: Check Object Match Criteria
Used by the routines at CountObjectsInLocation and FindMatchingObject.
Sets the carry when the object matches the id, the location and the remaining checks. Returns with the carry clear when any check fails.
Input
A Object ID
B Location ID
Output
F Carry flag set if object matches all criteria (location, visibility, type, etc.)
CheckObjectMatchCriteria D4EF CP (IY+$01) Go to CheckObjectMatchCriteria_NoMatch if the object id does not match.
D4F2 JR NZ,CheckObjectMatchCriteria_NoMatch
D4F4 LD A,($A036) Go to CheckObjectMatchCriteria_NoMatch if the object is the character being processed.
D4F7 CP (IX+$00)
D4FA JR Z,CheckObjectMatchCriteria_NoMatch
