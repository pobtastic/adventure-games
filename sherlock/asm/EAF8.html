EAF8: Copy The Character Onto Both Records
Copies the character being processed onto the two records and gives both the location 32. Reached from the script command at EA5F, run by DispatchCharacterScript. Run by CA64 after the display record at EAF6. A non-zero return means the script step succeeded.
CopyCharacterOntoBothRecords EAF8 LD A,($A034) Read the room display parameter.
EAFB LD IX,($A015) Store that id at offset 01 of the record at A015.
EAFF LD (IX+$01),A
EB02 LD (IX+$0F),$32 Give that record the location 32.
EB06 LD IX,($A013) Give the record at A013 the location 32.
EB0A LD (IX+$0F),$32
EB0E OR %00000001 Reset the zero flag.
EB10 RET Return.
