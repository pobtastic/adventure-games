B033: Step Display State When Parser Clear
Takes the next display-state step when the parser flag is clear, sets that flag, and copies the display. Reached through the standard command table at Table_CommandHandlerLookup_Standard, dispatched by AFE0.
StepDisplayStateWhenParserClear B033 CALL TestSourceBitOne Call TestSourceBitOne to test the low flag bit.
B036 LD A,($A01A) Jump to CopyBytes_ReportSuccess if the parser is set.
B039 AND A
B03A JP NZ,CopyBytes_ReportSuccess
B03D LD A,$01 Write 01 to the parser.
B03F LD ($A01A),A
B042 SET 7,(IY+$01) Set bit 7 of IY+01.
B046 JP CopyDisplayIfNeeded Jump back to CopyDisplayIfNeeded to copy display if needed.
