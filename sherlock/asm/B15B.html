B15B: Initialise When Flagged
Initialises the character when bit 3 of the display flags is present. Reached through the alternate command table at Table_CommandHandlerLookup_Alternate, dispatched by AFE0.
InitialiseWhenFlagged B15B BIT 3,E Jump ahead to InitialiseWhenFlagged_MarkBitSix if bit 3 is clear.
B15D JR Z,InitialiseWhenFlagged_MarkBitSix
B15F PUSH DE Call FollowCharacterLink to follow the character link, saving source.
B160 CALL FollowCharacterLink
B163 CALL InitialiseCharacterDataStructure Call InitialiseCharacterDataStructure to initialise character data structure.
B166 POP DE
