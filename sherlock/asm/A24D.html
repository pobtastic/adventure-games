A24D: Token Word Table
Eight token words. PrintTokenBasedOnParameters indexes them from the token parameter, and uses the half at A255 when the print mode or the object display flag is set. Used by PrintTokenBasedOnParameters.
A24D DEFW $089D "THE".
A24F DEFW $0001 "A".
A251 DEFW $005A "AN".
A253 DEFW $080A "SOME".
A255 DEFW $089D "THE".
A257 DEFW $089D "THE".
A259 DEFW $089D "THE".
A25B DEFW $080A "SOME".
