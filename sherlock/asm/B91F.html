B91F: Check The Character Being Processed
Used by the routines at B90E and ProcessCharacterAction.
Compares the character being processed with each display link. The zero flag is set when one matches.
Output
F Zero flag set if object found, bit 0 set if not found

B92B CP (IX+$00) See whether it matches the record flag.
