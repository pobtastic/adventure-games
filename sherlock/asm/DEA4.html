DEA4: Set Bit Five Of The Current Object
Sets bit 5 of the current object's flags and marks success. Handler placed after the display record at DE9D. ClearCurrentObjectBitFive clears the bit this handler sets. Run by CA64 after the display record at DE9D.
SetCurrentObjectBitFive DEA4 LD IX,($A013) Read the current object.
DEA8 SET 5,(IX+$05) Set bit 5 of its flags.
DEAC OR %00000001 Reset the zero flag.
DEAE RET Return.
DEAF DEFB $38,$10,$00,$20,$00,$00,$00 Display record read by ProcessDisplayRecord: flags 38 value 10 parameters 00 20 00 00 00.
