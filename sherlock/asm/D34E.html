D34E: Search Three-Byte Length Table
Used by the routines at Handler_FindCharacterAction, CheckTextTokenMatch, ProcessObjectDisplayLogic, FetchObjectDataPointer, LookupAndPrintDisplayText, TestEndMarker_WalksThreeByte and FindResponseForThisId.
Walks a list of three-byte groups until the end marker.
Input
A Table ID to match
IX Table to search
Output
A Entry ID or FF for no entry found
IX Pointer to found entry
F The zero flag is set when no entry was found
SearchThreeByteTable D34E EXX Switch to the shadow registers.
D34F LD E,$03 Set the length of the data in E (03 bytes).
