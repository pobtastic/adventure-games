E5C1: Display Record
Display record read by ProcessDisplayRecord. The show-message command at E781 passes this word to ProcessDisplayRecordFromScript.
Named from the script command at E781.
E5C1 DEFB $00,$00 Display record read by ProcessDisplayRecord: flags 00 value 00.
