CC37: Process Character Action
Used by the routine at Game_Initialisation.
Clears the script command counter at CC0B, then runs FindCharacter.
Input
A Character ID
ProcessCharacterAction CC37 PUSH AF Save the character id and clear the script command counter at CC0B.
CC38 XOR A
CC39 LD ($CC0B),A
CC3C POP AF Call FindCharacter to find character.
CC3D CALL FindCharacter
CC40 CP $FF Was the character ID found?.
CC42 LD HL,$0001 Take 0001 in HL and jump ahead to NoteDisguiseAndReadTimetable_RecordCharacterScript if FindCharacter did not find the character.
CC45 JP Z,NoteDisguiseAndReadTimetable_RecordCharacterScript
The character is active in the timetable.
CC48 LD ($9FDB),IY Write the characters timetable pointer to *CurrentCharacter_TimetablePointer.
CC4C LD ($A036),A Write the character ID to *CurrentCharacter_ID.
CC4F CALL CheckCharacterBeingProcessed Go to ProcessCharacterAction_0 if this character is not in the display list.
CC52 LD A,$00
CC54 JR NZ,ProcessCharacterAction_0
CC56 INC A Count one more.
ProcessCharacterAction_0 CC57 LD ($CC0D),A Store it in the display-list flag at CC0D.
