CFB6: Find Character Script Entry
Used by the routines at MeasureCharacterDistance, DispatchCharacterScript, GetScriptPointer, GetScriptPointerFromTimetable, UpdateScriptPointer, PlaceCharacter, ReadSourceDisplayPointer, StoreActionFlags and PrintActionMessage.
Searches through the character script entry list to find an entry matching the current character ID. Returns the entry pointer if found, otherwise returns 00.
Output
IX Character script entry pointer (if found)
A 00 if not found, bit 0 set if found
FindCharacterScriptEntry CFB6 LD A,($A036) Read the current character.
