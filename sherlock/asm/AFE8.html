AFE8: Test Bit 1 Of The Source
Used by the routine at StepDisplayStateWhenParserClear.
Returns to the caller when bit 1 of E is clear, and also when the game has started and pictures are disabled. Otherwise it drops the return address and leaves through CopyBytes_ReportSuccess.
TestSourceBitOne AFE8 BIT 1,E See whether bit 1 of the source is set.
AFEA RET Z Return if that marker is clear.
AFEB LD A,($A012) Jump to TestSourceBitOne_DropReturn if the pictures-enabled byte at A012 is set.
AFEE AND A
AFEF JR NZ,TestSourceBitOne_DropReturn
AFF1 LD A,($A01B) Return if the initialised flag is set.
AFF4 AND A
AFF5 RET NZ
TestSourceBitOne_DropReturn AFF6 POP HL Jump back to CopyBytes_ReportSuccess to return non-zero.
AFF7 JP CopyBytes_ReportSuccess
