A7B4: Describe The Next Token
Fetches the next token and joins DescribeTheDisplayedRoom_SetFlag with the token's high byte in A. DescribeThisCharacter_StoredFlag then describes that value the same way DescribeThisCharacter describes the character.
Control code 13 in the table at JumpTable_ControlCharacters.
Used by the routine at DispatchTextControlHandler.

A High byte of the token
