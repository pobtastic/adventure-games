B01C: Step Display State
Advances the room-display state when the parser flag at A019+01 is 01 builds the character record, and copies the display. Reached through the standard command table at Table_CommandHandlerLookup_Standard, dispatched by AFE0.
StepDisplayState B01C LD A,($A01A) Jump to CopyBytes_ReportSuccess if the parser is not 01.
B01F CP $01
B021 JP NZ,CopyBytes_ReportSuccess
B024 LD A,$02 Store 02 at A019+01 and call InitialiseCharacterDataStructure to initialise the character.
B026 LD ($A01A),A
B029 CALL InitialiseCharacterDataStructure
B02C SET 6,(IY+$01) Jump back to CopyDisplayIfNeeded to copy display if needed.
B030 JP CopyDisplayIfNeeded
