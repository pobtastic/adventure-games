A5CD: Process Text Command
Used by the routines at ProcessTextStream and PrintRandomAlternative.
Reads the next text byte. A command keeps its parameter, and any other byte is printed as text.
Input
IX Pointer to text data
ProcessTextCommand A5CD LD A,(IX+$00) Jump ahead to TestSpace if bit 7 of the record's flag byte is clear.
A5D0 BIT 7,A
A5D2 JR Z,TestSpace
A5D4 AND %01111111 Strip the command marker (bit 7) to leave the token code.
A5D6 LD D,A Keep the token code in D and its parameter in E, and step IX onto that parameter.
A5D7 LD E,(IX+$01)
A5DA INC IX
A5DC AND %11110000 Keep the token type (the high nibble) for the checks below.
A5DE CP $30 Go to PrintCharacterWithTimePeriod when the token type is 30.
A5E0 JR Z,PrintCharacterWithTimePeriod
A5E2 CP $20 Go to PrintCharacterWithTimePeriod when the token type is 20.
A5E4 JR Z,PrintCharacterWithTimePeriod
A5E6 CP $60 Go to PrintCharacterWithTimePeriod when the token type is 60.
A5E8 JR Z,PrintCharacterWithTimePeriod
