D3D5: Take The Found Object
Used by the routines at DescribeCurrentRoom, PrintObjectDescription, PrintLocationExits and PrintObjectDescriptionText.
Points IY at the object just found and continues at TakeTheFoundObject_DescriptionFlag. That entry steps seven bytes to the description flag and calls CheckObjectHasSpecialDescription.
TakeTheFoundObject D3D5 PUSH IX Copy the object record from IX into IY.
D3D7 POP IY
This entry point is used by the routine at PrintFormattedObjectList.
TakeTheFoundObject_DescriptionFlag D3D9 PUSH IY Keep the object and step seven bytes to its description flag.
D3DB PUSH DE
D3DC LD DE,$0007
D3DF ADD IY,DE
D3E1 CALL CheckObjectHasSpecialDescription Call CheckObjectHasSpecialDescription to see whether this object has a special description.
D3E4 POP DE Restore the saved source and the saved schedule entry from the stack.
D3E5 POP IY
D3E7 RET Return.
