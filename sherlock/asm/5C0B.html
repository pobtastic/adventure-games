5C0B: Word Buffer
Word-wrap buffer used by the game. Print_Character stores each letter here through *BufferPointer until a space, newline or quote; A9F6 then prints those letters and resets the pointer to WordBuffer. It overlays the system variables from DEFADD onwards. The store path has no hard length check; the flush path treats the buffered length as an 8-bit count and compares it with the screen width at ScreenWidth (set to 12 or 24), so this block is sized to that maximum width (24).
