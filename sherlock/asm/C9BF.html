C9BF: Process Display Record
Used by the routine at ProcessObjectDisplayEntry.
HL points at a display record (flags, value, optional handler word, optional five extra bytes). Checks the record against the current object, character and graphics, runs its handler if bit 6 is set, and then either returns the address after the record (bit 7 set) or runs the code that follows it via CA64. A non-zero return means the script step succeeded.
ProcessDisplayRecord C9BF PUSH HL Point IY at the display record and call CheckObjectVisibility to check whether the object is visible.
C9C0 POP IY
C9C2 CALL CheckObjectVisibility
C9C5 JR NC,ProcessDisplayRecord_TestHandler Go to ProcessDisplayRecord_TestHandler if CheckObjectVisibility finds the object is not visible.
Bit 5 of the record flags is clear?
C9C7 LD A,(IY+$00) Jump to ProcessDisplayRecord_TestHandler if bit 5 of the record flags is clear.
