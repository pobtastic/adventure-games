B173: Display Mode Flag
Flag controlling display mode (bit 7 indicates special display mode). Read by CheckFlagAndSetDisplay, FindFirstNoun and SelectJumpIfNotZero.
DisplayModeFlag B173 DEFB $00
B174 DEFW $0000 Saved display pointer, read by InitialiseDisplayBuffer.
B176 DEFW $0000 Saved display pointer, read by InitialiseDisplayBuffer.
B178 DEFB $00 Low byte of the display mode word, read by SwapObjectDisplayPointers, CheckFlagAndSetDisplayParameter, TestEndMarker, UnlinkNextDisplayRecord, SelectJumpIfNotZero, CalculateObjectPointerOffset and ReadCharacterRecordValue.
B179 DEFB $00 High byte of the display mode flag, read by CheckFlagAndSetDisplayParameter, MatchSecondNoun and SelectJumpIfNotZero.
B17A DEFB $00,$00,$00,$00 Bytes beside the display mode word.
