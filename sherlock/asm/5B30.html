5B30: Tape Loader: Game
Loads the game header and the code block it names, and resets the Spectrum if either load fails or the header is not a code file. Called from the loader bytes at 5B10 and 5B18.
Read the game header from tape.
TapeLoader_Game 5B30 LD IX,$5B1E Point IX at the tape header (5B1E), request 11 bytes, and ask the ROM routine to load rather than verify.
5B34 LD DE,$0011
5B37 XOR A
5B38 SCF
5B39 CALL TapeLoader_LoadBytes Call TapeLoader_LoadBytes to load the next tape block.
Give up unless the header loaded.
5B3C LD A,($5B2F) Reset the Spectrum unless the tape load result (5B2F) is 01.
5B3F DEC A
5B40 JP NZ,$0000
The header must describe a code block.
5B43 LD A,($5B1E) Reset the Spectrum unless the header type at 5B1E is 03.
5B46 CP $03
5B48 JP NZ,$0000
