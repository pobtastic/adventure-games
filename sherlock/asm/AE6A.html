AE6A: Initialise Character Data Structure
Used by the routines at AAB2, B01C, ProcessCharacterData, B13F and B15B.
Initialises a character data structure by finding the character with ID 1E storing the pointer to it in the previous character data location, and setting IY to point to the new character data.
