ACCC: Process Text Token And Save State
Used by the routines at AAB2, AB52 and AFFA.
Processes text tokens until a non-A0 token is found, then saves the current text processing state (pointer, flags, and display mode) to the display buffer structure.
Input
E Flags (bit 3 is reset)
