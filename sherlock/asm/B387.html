B387: Read The Object Attribute
Used by the routine at InitialiseDisplayBuffer.
Returns the object attribute when its bit 2 is clear, or when bit 0 of B16E is set. Returns zero when bit 1 of the attribute is set.
ReadObjectAttribute B387 LD A,($A01D) Read the object attribute.
B38A BIT 2,A See whether bit 2 of it is set.
B38C RET Z Return if that marker is clear.
B38D LD HL,$B16E Point at the display flag.
B390 BIT 0,(HL) See whether the display flag is set.
B392 RET NZ Return if that marker is set.
B393 BIT 1,A Jump ahead to ReadObjectAttribute_SignalStepFailed if bit 1 of the attribute is set.
B395 JR NZ,ReadObjectAttribute_SignalStepFailed
B397 OR %00000001 Reset the zero flag.
B399 RET Return.
ReadObjectAttribute_SignalStepFailed B39A XOR A Clear A.
B39B RET Return.
