C4B2: Check Display Flag Bits 2 And 6
Used by the routines at ProcessObject_Display, InitialiseDisplayBuffer and ProcessDisplayAction.
Tests bits 2 and 6 of the object attribute at ObjectAttributeValue. When both allow it, the display flag chooses the mode.
CheckDisplayBitsTwoAndSix C4B2 XOR A Point HL at the object attribute and go to CheckDisplayBitsTwoAndSix_0 if bit 2 is clear.
C4B3 LD HL,$A01D
C4B6 BIT 2,(HL)
C4B8 JR Z,CheckDisplayBitsTwoAndSix_0
C4BA LD A,$04 Go to CheckDisplayBitsTwoAndSix_0 if bit 6 of the object attribute is set.
C4BC BIT 6,(HL)
C4BE JR NZ,CheckDisplayBitsTwoAndSix_0
C4C0 LD A,($A01E) Read the display.
Bits 0 and 1 of the display flag choose the mode.
C4C3 AND $03 Jump to CheckDisplayBitsTwoAndSix_0 with 05 if bits 0 and 1 of the display flag are both set.
C4C5 CP $03
C4C7 LD A,$05
C4C9 JR Z,CheckDisplayBitsTwoAndSix_0
C4CB LD A,$07 Use 07 for the display.
CheckDisplayBitsTwoAndSix_0 C4CD LD ($A010),A Store it in the display mode.
C4D0 RET Return.
