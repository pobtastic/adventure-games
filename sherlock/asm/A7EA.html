A7EA: Token Match Flag
Cleared by CheckTokenMatchAndSetFlag, then set when the token is not the special match. CheckObjectHasSpecialDescription clears it again unless bit 6 of the record is set, and A815 folds it into the token format flag. Used by CheckTokenMatchAndSetFlag, A815 and CheckObjectHasSpecialDescription.
