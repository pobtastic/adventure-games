E70E: Display Record
Display record read by ProcessDisplayRecord. The show-message command at F35C passes this word to ProcessDisplayRecordFromScript.
Named from the script command at F35C.
E70E DEFB $00,$00 Display record read by ProcessDisplayRecord: flags 00 value 00.
