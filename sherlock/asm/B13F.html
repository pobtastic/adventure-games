B13F: Follow Link When Flagged
Follows the link when bit 3 of the display flags is present. Reached through the alternate command table at Table_CommandHandlerLookup_Alternate, dispatched by AFE0.
FollowLinkWhenFlagged B13F BIT 3,E Jump ahead to FollowLinkWhenFlagged_MarkTopBit if bit 3 is clear.
B141 JR Z,FollowLinkWhenFlagged_MarkTopBit
B143 PUSH DE Call FollowCharacterLink to follow the character link, saving source.
B144 CALL FollowCharacterLink
B147 CALL InitialiseCharacterDataStructure Call InitialiseCharacterDataStructure to initialise character data structure.
B14A POP DE
This entry point is used by the routine at SetDisplayMode_SelectsPictureMode.
Set the mark on this character.
FollowLinkWhenFlagged_MarkTopBit B14B SET 7,(IY+$19) Set bit 7 of IY+19 and jump back to ProcessCharacterData_0.
B14F JR ProcessCharacterData_0
