D21C: Fetch Next Object With ID
Used by the routines at ProcessObjectLocationRecursively, ScanObjectsId and FindMatchingObject.
Keeps the id and steps to the next object.
Input
A Object ID to search for
Output
A Object ID that was searched for
F Zero flag set when there is no further object
FetchNextObjectWithID D21C PUSH BC Call FetchNextObject to fetch next object.
D21D LD B,A
D21E CALL FetchNextObject
D221 LD A,B Read the count.
D222 POP BC Restore BC from the stack.
