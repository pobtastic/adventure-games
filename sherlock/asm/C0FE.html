C0FE: Tape Header: Saved Game
Header for the save and load blocks. The name begins SHD V2. Read by SaveGame and LoadGame.
C0FE DEFB $03 Type.
C0FF DEFM "SHD V2.0 " Name.
C109 DEFW $0000 Saved-game length, read by SaveGame, LoadGameData and LoadGame.
C10B DEFW $0000 Address the saved game loads to, read by SaveGame, LoadGameData and LoadGame.
C10D DEFW $8000 Parameter.
