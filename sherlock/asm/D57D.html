D57D: Find The Next Matching Object
Used by the routine at PrintFormattedObjectList.
Finds the next object with this id, and gives up when the list ends or the object is not here.
FindMatchingObject D57D CALL FetchNextObjectWithID Call FetchNextObjectWithID to fetch the next object with this id.
D580 JR NZ,FindMatchingObject_CheckCriteria Go to FindMatchingObject_CheckCriteria if another object remains.
Object not found, so return that failure to the caller.
D582 SCF Set the carry to report that no object was found.
D583 RET Return.
Read the record flag.

D585 CALL CheckObjectMatchCriteria
D588 JR NC,FindNextMatchingObject Go to FindNextMatchingObject if CheckObjectMatchCriteria does not match this object.
Object matches - return with object ID.
FindMatchingObject_Found D58A POP AF Restore the saved result from the stack.

D58E AND A Clear the carry to report that this object was found.
