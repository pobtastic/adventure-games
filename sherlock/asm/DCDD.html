DCDD: Read The Schedule Entry From The Current Character
Used by the routine at ParseInputNumber.
Fails the script unless the character's script position and location allow the object description. A non-zero return means the script step succeeded.
ReadScheduleEntryFromCurrentCharacter DCDD CALL CheckFlagAndJumpToNewline Call CheckFlagAndJumpToNewline to check the flag and start a new line.
DCE0 LD IY,($A017) Read the current character record.
DCE4 LD A,(IY+$01) Jump to ParseInputNumber_ReturnZero unless IY+01 is FF.
DCE7 CP $FF
DCE9 JP NZ,ParseInputNumber_ReturnZero
DCEC LD A,(IX+$02) Return zero through ParseInputNumber_ReturnZero if the location is zero.
DCEF AND A
DCF0 JP Z,ParseInputNumber_ReturnZero
DCF3 LD A,(IX+$01) Load the byte at IX+01 and call DescribeObjectIfPresent.
DCF6 CALL DescribeObjectIfPresent
DCF9 JP NZ,ParseInputNumber_ReturnZero Return zero through ParseInputNumber_ReturnZero if DescribeObjectIfPresent returns non-zero.
DCFC OR %00000001 Reset the zero flag.
DCFE RET Return.
