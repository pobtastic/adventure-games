A7C5: Check Object Has Special Description
Used by the routine at ProcessObjectAttribute.
The same sequence as CheckObjectAttributeWithFlag_Wrapper. Keeps the schedule entry, points IY at the object, and calls CheckObjectHasSpecialDescription to test the special-description flag.
Input
HL Object pointer
CheckObjectHasSpecialDescription_Wrapper A7C5 PUSH IY Save the schedule entry.
A7C7 PUSH HL Copy the object pointer from HL into IY.
A7C8 POP IY
A7CA CALL CheckObjectHasSpecialDescription Call CheckObjectHasSpecialDescription to check if the object has a special description (bit 6).
A7CD POP IY Restore the saved schedule entry from the stack.
A7CF RET Return.
