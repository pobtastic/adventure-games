D495: Get Object First Location
Used by the routines at CheckCharacterDisguise, ProcessCharacterDisplay_TestDisplayFlagEnd, SetCharacterPointerAndID and IsSherlockTheChinaMan.
Returns at once when the id is FF. Otherwise looks the object up. Returns FF when the object appears more than once, and the first location at offset 0F when it appears once.
Input
A Object ID
Output
A FF when the id is empty or the object appears more than once, else its first location

D49D CP (IX+$00)
D4A0 LD A,$FF Leave FF when the object appears more than once.
D4A2 RET NZ Return if the object appears more than once.
The object appears once, so return its first location.
