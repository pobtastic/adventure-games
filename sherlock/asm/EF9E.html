EF9E: Set The Print Flag And Print
Sets the print flag, prints the message in hand, and marks success.
Run by CA64 after the display record at EF9C, from the show-message command at EE95.
SetPrintFlagAndPrint EF9E LD HL,$75E8 Take the message at 75D2+16.
This entry point is used by the routine at PrintHandlerMessage.
SetPrintFlagAndPrint_0 EFA1 LD A,$01 Set the print flag (TV_FLAG).
EFA3 LD ($5C3C),A
EFA6 CALL PrintTextAndHandleControlCharacters Call PrintTextAndHandleControlCharacters to print the message.
EFA9 OR %00000001 Reset the zero flag.
EFAB RET Return.
