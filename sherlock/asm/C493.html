C493: Check Display Flag Bits 3 And 7
Used by the routines at ProcessObject_Display, InitialiseDisplayBuffer and ProcessDisplayAction.
Tests bits 3 and 7 of the object attribute at ObjectAttributeValue. When both allow it, the display flag chooses the mode.
CheckDisplayBitsThreeAndSeven C493 XOR A Point HL at the object attribute and go to CheckDisplayBitsThreeAndSeven_0 if bit 3 is clear.
C494 LD HL,$A01D
C497 BIT 3,(HL)
C499 JR Z,CheckDisplayBitsThreeAndSeven_0
C49B LD A,$04 Go to CheckDisplayBitsThreeAndSeven_0 if bit 7 of the object attribute is set.
C49D BIT 7,(HL)
C49F JR NZ,CheckDisplayBitsThreeAndSeven_0
C4A1 LD A,($A01E) Read the display.
Bits 2 and 3 of the display flag choose the mode.
C4A4 AND $0C Jump to CheckDisplayBitsThreeAndSeven_0 with 05 if bits 2 and 3 of the display flag are both set.
C4A6 CP $0C
C4A8 LD A,$05
C4AA JR Z,CheckDisplayBitsThreeAndSeven_0
C4AC LD A,$07 Use 07 for the display.
CheckDisplayBitsThreeAndSeven_0 C4AE LD ($A00F),A Store it in the display mode.
C4B1 RET Return.
