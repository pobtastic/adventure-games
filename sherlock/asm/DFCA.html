DFCA: Display Record
Display record read by ProcessDisplayRecord. The show-message command at EF99 passes this word to ProcessDisplayRecordFromScript.
Named from the script command at EF99.
DFCA DEFB $00,$00 Display record read by ProcessDisplayRecord: flags 00 value 00.
