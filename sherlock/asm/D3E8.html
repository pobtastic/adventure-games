D3E8: Check Object Has Special Description
Used by the routines at CheckObjectHasSpecialDescription_Wrapper, ProcessTextTokenEntry and TakeTheFoundObject.
Reads the object's description word through CheckTokenMatchAndSetFlag and clears A7EA unless bit 6 of IY-02 is set. Then prints the tokens at IY+02 and IY+04 or only the one at IY+04 when bit 5 of IY-01 is set.
CheckObjectHasSpecialDescription D3E8 PUSH AF Save the registers, then read the word at IY+00-01 into DE.
D3E9 PUSH DE
D3EA LD D,(IY+$01)
D3ED LD E,(IY+$00)
D3F0 CALL CheckTokenMatchAndSetFlag Call CheckTokenMatchAndSetFlag to test the token and set the flag.
D3F3 BIT 6,(IY-$02) Go to CheckObjectHasSpecialDescription_Next if bit 6 of this byte is set.
D3F7 JR NZ,CheckObjectHasSpecialDescription_Next
D3F9 XOR A Clear the token match flag at A7EA.
D3FA LD ($A7EA),A
CheckObjectHasSpecialDescription_Next D3FD BIT 5,(IY-$01) Go to ReadScheduleField if bit 5 of this byte is set.
D401 JR NZ,ReadScheduleField
D403 JR $D416 Go on to read the high byte of the object's description token.
