DAE8: Test For A Digit
Used by the routines at ReadCommandLine_CommandLinePrints, TestCommonWord, TestComma, StartParsedNumber and ParseInputNumber.
Sets the carry when A is not a digit (30 to 39).
TestDigit DAE8 CP $30 Return if it is below 30.
