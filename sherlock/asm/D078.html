D078: Check Object Visibility
Used by the routines at ProcessObjectDisplay, ProcessDisplayRecord and ProcessObjectDisplayWithCheck.
Sets the carry when the current character is visible and a matching object is found. Returns with the carry clear when the character is not visible.
