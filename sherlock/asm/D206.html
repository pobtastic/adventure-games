D206: Fetch Next Object
Used by the routines at CheckObjectVisibility, FetchNextObjectWithID, ProcessObjectEntry, ReadCharacterRoom, FindObjectByField and CountObjectsInLocation.
Steps to the next object in the list and reports whether the list has ended.
Input
IX Pointer to objects table
Output
IX Pointer to object table
IY Pointer to object data
F The zero flag is set if the end of the table is reached
FetchNextObject D206 EXX Switch to the shadow registers.
D207 LD DE,$0003 Step to the next object record.
D20A ADD IX,DE
D20C LD D,(IX+$02) Read the next object's data pointer.
D20F LD E,(IX+$01)
D212 PUSH DE
D213 POP IY
D215 LD A,(IX+$00) Stop at the end of the object table (FF).
D218 CP $FF
D21A EXX Switch back to the normal registers.
D21B RET Return.
