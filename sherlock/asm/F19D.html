F19D: Reject A Lower Character Id
Returns zero when the character being processed is below the id passed in. A non-zero return means the script step succeeded.
RejectLowerCharacterId F19D LD B,A Return zero through ParseInputNumber_ReturnZero if the character being processed is below this id.
F19E LD A,($A034)
F1A1 CP B
F1A2 JP C,ParseInputNumber_ReturnZero
F1A5 OR %00000001 Reset the zero flag.
F1A7 RET Return.
