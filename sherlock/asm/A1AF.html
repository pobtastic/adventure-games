A1AF: Follow Record Pointer
Used by the routines at ApplySavedClause, ProcessLocationDisplay, RecordResultCharacterScript, ReadFirstDisplayLink and ReadNextDisplayLink.
Copies the character-record pointer and jumps to the routine that pointer holds.
Input
IX Pointer to jump to
HL (preserved on stack)
FollowRecordPointer A1AF PUSH HL Keep the pointer, copy the record into it, and go to FollowRecordPointer_0.
A1B0 PUSH IX
A1B2 POP HL
A1B3 JR FollowRecordPointer_0
Walks the linked character records from the link stored just ahead of the current record, running each one until the link is empty.
FollowRecordPointer_ReadLink A1B5 LD L,(IX-$02) Read the pointer saved ahead of this record, then call ProcessMemoryEntry to run memory entry.
A1B8 LD H,(IX-$01)
A1BB CALL ProcessMemoryEntry
A1BE PUSH HL Use the saved pointer as the character record.
A1BF POP IX
Loop while the link just read is not zero.
FollowRecordPointer_0 A1C1 LD A,L Jump back to FollowRecordPointer_ReadLink while the pointer is not zero.
A1C2 OR H
A1C3 JR NZ,FollowRecordPointer_ReadLink
A1C5 POP HL Restore the saved pointer from the stack.
A1C6 RET Return.
