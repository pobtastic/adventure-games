D0D0: Write Token To Buffer
Used by the routines at ProcessLocationToken and DescribeCurrentRoom.
Writes the current text token into the message pointer at 68DE, with the top bit set so the printer treats it as a token.
Input
HL Pointer to output buffer
DE Token value (word)
WriteTokenToBuffer D0D0 PUSH DE Use the text pointer (68DE).
D0D1 LD DE,$68DE
D0D4 EX DE,HL
D0D5 SET 7,D
D0D7 LD (HL),D
D0D8 INC HL Advance through the text.
D0D9 LD (HL),E Store that byte at the pointer.
D0DA POP DE Restore DE from the stack.
D0DB RET Return.
