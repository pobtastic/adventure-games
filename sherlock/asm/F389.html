F389: Compare The Room Parameters
Compares the character being processed with the two room parameters. A non-zero return means the script step succeeded.
Handler word in the display record at F380, called via CB34.
CompareRoomParameters F389 LD IX,($A013) Point IX at the current object (A013).
F38D LD A,($A036) Read the character being processed and count down one.
F390 DEC A
F391 CP (IX+$01) Compare it with byte 01 of that object.
F394 JP NZ,ParseInputNumber_ReturnZero Go to ParseInputNumber_ReturnZero if they differ.
F397 LD HL,$A034 Point HL at the room display parameter at RoomDisplayParameter.
F39A INC A Bring the character id back up by one and compare it with the room display parameter.
F39B CP (HL)
F39C JP Z,ParseInputNumber_ReturnZero Go to ParseInputNumber_ReturnZero if it matches the room display parameter.
F39F OR %00000001 Reset the zero flag.
F3A1 RET Return.
