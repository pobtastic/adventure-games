DAEF: Parse A Time
Used by the routine at TestCommonWord.
Reads hours, an optional ":" and minutes into B/C, then an "A" or "P" plus "M" suffix. "A" sets bit 6 of B; "P" sets bit 6 of C for PM.
ParseATime DAEF CALL ParseInputNumber Call ParseInputNumber to start from an empty length.
DAF2 LD B,A Jump ahead to ParseATime_CheckHours if this byte is 3A.
DAF3 LD A,(HL)
DAF4 CP $3A
DAF6 JR Z,ParseATime_CheckHours
DAF8 CP $41 Jump ahead to ParseATime_CheckHours when the input character is A.
DAFA JR Z,ParseATime_CheckHours
DAFC CP $50 Jump ahead to ParseATime_CheckHours when the input character is P.
DAFE JR Z,ParseATime_CheckHours
DB00 CALL TestFullStop_TestReturnsCharacterSentence Jump ahead to StartParsedNumber unless the character is a full stop, a comma or a space.
DB03 JR NZ,StartParsedNumber
ParseATime_CheckHours DB05 LD A,B Jump ahead to ParseATime_SignalNothingMatched if the count is at least 3C.
DB06 CP $3C
DB08 JR NC,ParseATime_SignalNothingMatched
DB0A SET 7,B Set bit 7 of the count.
DB0C LD C,$00 Start the number at zero, read the input character, and parse it.
DB0E LD A,(HL)
DB0F CALL TestFullStop_TestReturnsCharacterSentence
DB12 JR Z,TestComma_0 Go to TestComma_0 if the character is a full stop, a comma or a space.
ParseATime_ReadMinutes DB14 CP $3A Jump ahead to ParseATime_CheckSuffix if the character is not 3A.
DB16 JR NZ,ParseATime_CheckSuffix
DB18 INC HL Step to the next character and call ParseInputNumber to read a number.
DB19 CALL ParseInputNumber
DB1C LD C,A Jump ahead to ParseATime_SignalNothingMatched if the number is at least 3C.
DB1D CP $3C
DB1F JR NC,ParseATime_SignalNothingMatched
ParseATime_CheckSuffix DB21 LD A,(HL) Jump ahead to TestComma_0 if the character is a full stop, a comma or a space.
DB22 CALL TestFullStop_TestReturnsCharacterSentence
DB25 JR Z,TestComma_0
DB27 CP $41 Jump ahead to ParseATime_AMPM if the character is not 41.
DB29 JR NZ,ParseATime_AMPM
DB2B SET 6,B Set bit 6 of the count.
DB2D INC HL Step to the next input character and continue at ParseATime_CheckM.
DB2E JR ParseATime_CheckM
Accept "AM" or "PM": "A" has already set bit 6 of B, and "P" sets bit 6 of C for PM; both then require "M".
ParseATime_AMPM DB30 CP $50 Jump ahead to ParseATime_SignalNothingMatched if the character is not 50.

DB34 SET 6,C Set bit 6 of C for PM and step to the next character.
DB36 INC HL

DB38 CP $4D
DB3A JR NZ,ParseATime_SignalNothingMatched
