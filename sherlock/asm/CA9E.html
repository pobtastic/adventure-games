CA9E: Dispatch On The Schedule Marker
Used by the routine at ReadCharacterTimetable.
Reads the schedule entry and runs the object display when its marker is set.
DispatchScheduleMarker CA9E LD A,($DD01) Read the room at DD01 and the record at DCFF.
CAA1 LD HL,($DCFF)
CAA4 BIT 6,(HL) Go to ProcessObjectDisplayWithCheck if bit 6 of this byte is set.
CAA6 JP NZ,ProcessObjectDisplayWithCheck
CAA9 SET 6,(HL) Jump ahead to ProcessLocationTokenDisplay to run location token display.
CAAB JP ProcessLocationTokenDisplay
