AAC4: Choose The Display Path From The Initialised Flag
Used by the routine at RecordInputFlag.
Reads the initialised flag. When the game has been initialised it selects the alternate display path and clears the extra display marker.
AAC4 LD A,($A01B) Jump to StartPictureModeScreenIdle if the initialised flag is zero.
AAC7 AND A
AAC8 JR Z,StartPictureModeScreenIdle
AACA LD A,$01 Write 01 to the command mode at A024 and clear bit 3 of the source.
AACC LD ($A024),A
AACF RES 3,E
