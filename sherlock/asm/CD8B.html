CD8B: Terminate Character Script
Used by the routines at DispatchCharacterScript and ProcessScriptCommandWithCounter.
Ends this character's script by storing a one-cycle delay at CharacterScriptCycles and clearing the script state.
Set script completion flag.
TerminateCharacterScript CD8B LD HL,$0001 Write 0001 to *CharacterScriptCycles.
