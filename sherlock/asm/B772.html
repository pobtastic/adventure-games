B772: Read Dictionary High Nibble
Used by the routine at ProcessLocationDisplay.
Reads the high nibble of the dictionary byte at the token's index.
Input
D Character code
Output
A Attribute value (bits 4-7)
ReadDictionaryHighNibble B772 LD HL,$5DBF Take the dictionary index.
B775 LD A,D

B778 LD D,A Store the result in the high byte of the source.

B77A LD A,(HL) Read the dictionary byte this index points at.

B77D RET Return.
