CFB9: Walk The Character Script Entries
Used by the routine at TestCharacterAgainstRoom.
Starts at the first character-script entry and follows each link until this character is found.
FindCharacterScriptEntry_StartSearch CFB9 LD IX,$9FEB Use the character script entry list at CharacterScriptEntryList.
FindCharacterScriptEntry_Loop CFBD PUSH AF Keep the character being processed, then call FetchObjectPointerFromStack to fetch object pointer from stack.
CFBE CALL FetchObjectPointerFromStack
CFC1 JR Z,FindCharacterScriptEntry_NotFound Go to FindCharacterScriptEntry_NotFound if the object pointer is zero.
CFC3 POP AF
CFC4 CP (IX+$00) Go to FindCharacterScriptEntry_Loop if this entry is not the character being processed.
CFC7 JR NZ,FindCharacterScriptEntry_Loop
CFC9 OR %00000001 Mark that the entry was found.
CFCB RET Return with the entry pointer.
No matching entry was found in the list.
FindCharacterScriptEntry_NotFound CFCC POP AF Restore the caller's registers from the stack.
CFCD XOR A Set 00 (entry not found).
CFCE RET Return.
