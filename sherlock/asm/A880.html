A880: Extract Token From Text
Used by the routines at ProcessObject_Display and PrintObjectAttributeDescription.
Reads the next dictionary token from the message and keeps its low digit as the page.
Input
HL Pointer to text data
Output
DE Token value (word)
HL Updated pointer
Read the token value from the text data.
ExtractTokenFromText A880 LD E,(HL) Read this message byte and the one after it.
A881 INC HL
A882 LD A,(HL)
A883 INC HL
A884 AND %00001111 Keep only bits 0-3 (extract the low nibble from the second byte).
A886 LD D,A Keep the low digit as the dictionary page.
