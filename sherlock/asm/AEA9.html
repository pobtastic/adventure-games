AEA9: Follow Character Link
Used by the routines at MatchWordAgainstEarlierClause, StepToNextClauseRecord, ProcessCharacterData, FollowLinkWhenFlagged, InitialiseWhenFlagged, CheckFlagAndSetDisplay_CheckObjects, RecordResultCharacterScript and ReadActionFlags.
Reads the link stored ahead of the current character and hands that record back to the caller. It is empty when the list ends.
FollowCharacterLink AEA9 PUSH HL Read the link stored ahead of this character.
AEAA LD L,(IY-$02)
AEAD LD H,(IY-$01)
AEB0 LD A,H See whether the pointer is empty.
AEB1 OR L
AEB2 EX (SP),HL Point IY at the link that was in HL.
AEB3 POP IY
AEB5 RET Return.
