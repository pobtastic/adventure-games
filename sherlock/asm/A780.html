A780: Pronoun For This Character
Reads the current character and continues at PronounForThisCharacter_OtherId. A zero id returns token 09F2. Any other id returns token 0414. Either result is non-zero, so the caller prints the token.
Control code 0C in the table at JumpTable_ControlCharacters.
Used by the routine at DispatchTextControlHandler.

DE Pronoun token
