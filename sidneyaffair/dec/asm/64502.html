64502: Scroll Window Parameters
Parameters for ScrollWindow. BASIC POKEs them relative to "scr".
ScrollWindow_Fill 64502 DEFB 128,0,1 Fill bytes for the bottom line of the window (left, middle, right).
ScrollWindow_Lines 64505 DEFB 8 Number of pixel lines to scroll.
ScrollWindow_Left 64506 DEFB 8 Left column.
ScrollWindow_Top 64507 DEFB 0 Top pixel line.
ScrollWindow_Right 64508 DEFB 31 Right column.
ScrollWindow_Bottom 64509 DEFB 175 Bottom pixel line.
