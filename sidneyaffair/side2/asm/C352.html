C352: Draw Picture Parameters
Parameters for DrawPicture, read and written through IY. BASIC only POKEs the picture number here; *DrawPicture_Third and *DrawPicture_Thirds are always FF in the snapshot, so the routine takes the screen third and the number of thirds from the picture record.
The flags at DrawPicture_Flags:
Bit Relating To
00 Pixel data order (set: rows; clear: columns)
02 Set while a run of repeated bytes is being written
03 Set while the attributes are being drawn
DrawPicture_Number C352 DEFB $01 Picture number (01 for the first picture in the list).
DrawPicture_Third C353 DEFB $FF Screen third to start at, from 00 (top) to 02 (bottom). FF means use the value in the picture record.
DrawPicture_Thirds C354 DEFB $FF Number of thirds to draw, from 01 to 03. FF means use the value in the picture record.
DrawPicture_Flags C355 DEFB $0C Flags, copied from the picture record.
