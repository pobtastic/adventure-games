FB00: Display Frame Parameters
Parameters for DisplayFrame. BASIC POKEs them relative to "ins".
DisplayFrame_BufferBase FB00 DEFW PictureBuffer Buffer base address (E000 in the snapshot).
DisplayFrame_Number FB02 DEFB $01 Frame number (counting from 01).
DisplayFrame_PerRow FB03 DEFB $04 Frames in each row of the picture.
DisplayFrame_Width FB04 DEFB $08 Width of a frame, in characters.
DisplayFrame_Height FB05 DEFB $0A Height of a frame, in characters.
DisplayFrame_Column FB06 DEFB $19 Screen column to copy the frame to.
DisplayFrame_Row FB07 DEFB $03 Screen row to copy the frame to.
DisplayFrame_LineWidth FB08 DEFB $07 Width of a pixel line to copy, in bytes.
