FBF6: Scroll Window Parameters
Parameters for ScrollWindow. BASIC POKEs them relative to "scr".
ScrollWindow_Fill FBF6 DEFB $80,$00,$01 Fill bytes for the bottom line of the window (left, middle, right).
ScrollWindow_Lines FBF9 DEFB $08 Number of pixel lines to scroll.
ScrollWindow_Left FBFA DEFB $08 Left column.
ScrollWindow_Top FBFB DEFB $00 Top pixel line.
ScrollWindow_Right FBFC DEFB $1F Right column.
ScrollWindow_Bottom FBFD DEFB $AF Bottom pixel line.
