8006: Draw Picture: Unpack
Used by the routine at DrawPicture.
Continues from DrawPicture.
Find out where this code is in memory. The call leaves its return address (DrawPicture_ReturnAddress) just below the stack pointer. An interrupt at this point would overwrite it, so BASIC calls DisableInterrupts first and EnableInterrupts afterwards.
DrawPicture_Unpack 8006 CALL $007C Call the RET instruction at 007C, at the end of CH_ADD+1, which returns straight away.
DrawPicture_ReturnAddress 8009 DEC SP Move the stack pointer back down to the return address.
800A DEC SP
800B EX (SP),HL Swap it into HL, so HL=DrawPicture_ReturnAddress.
800C INC SP Move the stack pointer back up again.
800D INC SP
800E AND A Clear the carry flag ready for the subtraction.
800F LD DE,$0007 HL=DrawPicture_Number (DrawPicture_ReturnAddress less 0007).
8012 SBC HL,DE
8014 PUSH HL Stash the address of the parameters on the stack.
8015 POP IY Restore the address of the parameters from the stack into IY.
8017 LD DE,$012A HL=Graphics_Crosshair (DrawPicture_Number plus 012A), the first picture record.
801A ADD HL,DE
801B LD A,(IY+$00) A=the picture number from *DrawPicture_Number.

8025 JR DrawPicture_FindPicture Jump to DrawPicture_FindPicture.

803D LD A,(HL) Else write the record's number of thirds to *DrawPicture_Thirds.

Make sure the picture fits on the screen.
8046 LD A,(IY+$01) A=*DrawPicture_Third.
8049 CP $03 Jump to DrawPicture_Unpack_2 if the screen third is less than 03.

804D LD (IY+$01),$00 Else start at the top third (write 00 to *DrawPicture_Third).
DrawPicture_Unpack_2 8051 LD A,(IY+$02) A=*DrawPicture_Thirds.
8054 CP $04 Jump to DrawPicture_Unpack_3 if the number of thirds is less than 04.
8056 JR C,DrawPicture_Unpack_3
8058 LD (IY+$02),$01 Else draw one third (write 01 to *DrawPicture_Thirds).
DrawPicture_Unpack_3 805C ADD A,(IY+$01) Add the screen third to A. A still holds the number of thirds read at DrawPicture_Unpack_2, even when it has just been changed.
805F CP $04 Jump to DrawPicture_Unpack_4 if the picture ends on the screen (the total is less than 04).
8061 JR C,DrawPicture_Unpack_4
8063 LD (IY+$02),$01 Else draw one third (write 01 to *DrawPicture_Thirds).

Draw the pixels.
DrawPicture_Pixels 8071 INC HL Move HL on to the start of the picture data.
8072 LD E,$00 E=00 (the left-hand column).
8074 LD A,(IY+$01) A=*DrawPicture_Third.
8077 ADD A,A Multiply it by 08 as each third of the screen is 08 pages long.
8078 ADD A,A
8079 ADD A,A
DrawPicture_PixelsHighByte 807A ADD A,$40 Add the high byte of the start of the screen (40). BASIC POKEs this byte to draw into a buffer instead.
807C LD D,A Set D and C to the high byte of the top pixel line of the picture, so DE holds its screen address.
807D LD C,A

8090 LD B,$08 B=08 (pixel lines in a character row).
DrawPicture_LineLoop 8092 PUSH BC Stash the pixel line counter on the stack.
8093 LD B,$01 B=01 (one byte, for column order).
8095 BIT 0,(IY+$03) Jump to DrawPicture_Unpack_5 if bit 0 of *DrawPicture_Flags is clear (column order).
8099 JR Z,DrawPicture_Unpack_5
809B LD B,$20 Else B=20 (a whole pixel line, for row order).
DrawPicture_Unpack_5 809D PUSH DE Stash the screen address of this pixel line on the stack.
DrawPicture_ByteLoop 809E PUSH BC Stash the byte counter on the stack.
809F JR DrawPicture_FetchByte Jump to DrawPicture_FetchByte to write the next byte; it comes back to DrawPicture_NextByte.
DrawPicture_NextByte 80A1 POP BC Restore the byte counter from the stack.
80A2 INC DE Move right to the next screen byte.

80A5 POP DE Restore the screen address of this pixel line from the stack.
80A6 POP BC Restore the pixel line counter from the stack.
80A7 INC D Move down to the next pixel line.

80B2 POP BC Restore the character row counter from the stack.

80B8 LD D,A

80BE POP BC Restore the pass counter from the stack.
80BF DJNZ DrawPicture_PassLoop Decrease the pass counter by one and loop back to DrawPicture_PassLoop until all the passes are done.
