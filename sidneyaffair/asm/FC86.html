FC86: Print String
Prints the BASIC string "s$" at the current print position in a 64-column font. It finds the string with the ROM routine LOOK-VARS, using the name at PrintString_VariableName, and stops with an error if it is missing. Codes below 20 go straight to RST 10; codes from 90 upwards are skipped. Called by BASIC as "prn" (FC86).
