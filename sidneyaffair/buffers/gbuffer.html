Draw Picture Parameters
Parameters for DrawPicture, read and written through IY. BASIC only POKEs the picture number here; *DrawPicture_Third and *DrawPicture_Thirds are always FF in the snapshot, so the routine takes the screen third and the number of thirds from the picture record.
The flags at DrawPicture_Flags:
Bit Relating To
00 Pixel data order (set: rows; clear: columns)
02 Set while a run of repeated bytes is being written
03 Set while the attributes are being drawn
FB00 9
Display Frame Parameters
Parameters for DisplayFrame. BASIC POKEs them relative to "ins".
FBC3 4
Display Frame Work Space
Work space used by DisplayFrame for the screen and buffer character offsets of the frame.
FBF6 8
Scroll Window Parameters
Parameters for ScrollWindow. BASIC POKEs them relative to "scr".
FD02 1
Print String Half Flag
Half-character flag for PrintString.
FF76 12
Temporary Storage
Work space used by the routines above to hold the stack pointer while they switch to a temporary stack.
