41128: Flags: Already Seen Room Images
One bit for each entry in Table_RoomsWithImages. Handler_RoomExits sets the bit after the picture has been shown so the same room does not draw it again.
Flags_SeenRoomImages 41128 DEFB 1 Seen-image bits 0 to 7.
41129 DEFB 0 Seen-image bits 8 to 15.
41130 DEFB 0 Seen-image bits 16 to 23.
