44284: Handler: Dispatch Verb
Used by the routine at GameStart.
Matches the first input token from UserInput_FirstToken against the verb tokens at Table_VerbTokens. When a match is found, it indexes the verb script table at JumpTable_VerbScripts and runs that script through Handler_RunScript. When no match is found, it prints the rephrase message and returns.
Search the verb token list at Table_VerbTokens for the first user-input token.
Handler_DispatchVerb 44284 LD HL,46112 Point HL at the verb tokens table at Table_VerbTokens.
44287 LD BC,(48075) Load the verb-token count from *Count_VerbTokens into BC.
44291 LD A,(41275) Fetch the first user-input token from *UserInput_FirstToken into A.
44294 CPIR Search Table_VerbTokens for a matching token.
44296 JR Z,VerbMatched Jump to VerbMatched if a match was found.
The token is not a known verb.

44301 CALL PrintCompressedStringAndNewline Call PrintCompressedStringAndNewline to print that compressed string and a newline.
44304 RET Return.
