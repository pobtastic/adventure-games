46778: Table: Scenic Event Items
One item ID per scenic event (5 entries; see Count_ScenicEvents). These IDs are scenic-event slots in Table_ItemLocations / Table_InitialItemLocations: Table_ItemDescriptions has no description string for them (the pointer is 0000), so they have no display name in the item map. Handler_GameEvents passes each ID to ItemLocator to find the room that slot currently occupies, and Handler_ScenicEvents tests the same IDs with ValidateItemPresent.
