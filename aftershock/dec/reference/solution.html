Overview
Escape the damaged city, bridge the chasm, and restart the reactor backup systems.
Primary route: Classic Adventures Solution Archive file id 14 (https://solutionarchive.com/file/id,14/). Compass runs written as Ex3/Wx3 in that file are expanded here to E, E, E / W, W, W. Millard notes the Spectrum version prefers TAKE over GET.
  • Carry TV (or radio) for looters; do not carry it past the soldiers
  • Many red herrings - ignore them
Red Herrings
CASA lists: pen, radio, desk, tissues, pickaxe, diamond, stick, cap, trumpet, ticket, sweets and rusty nail. Tom Hayes's longer CASA FAQ (file id 8051) and Dorothy Millard's Tipshop walkthrough expand individual puzzles if this short route loses you.
Carry Rules
Tips: to pass soldiers on Manor Drive, do not carry the television; to cross waste ground / satisfy looters, do carry the television (or radio). Drop it once the looters are gone.
