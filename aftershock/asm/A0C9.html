A0C9: Turn-Based Event Counters
One counter byte for each bit in Flags_TurnEvents. Handler_GameEvents decreases the counter for every active event, and Action_SetTurnCounter stores a new count.
TurnEventCounters A0C9 DEFB $00 Counter for event bit 00.
A0CA DEFB $00 Counter for event bit 01.
A0CB DEFB $00 Counter for event bit 02.
A0CC DEFB $00 Counter for event bit 03.
A0CD DEFB $00 Counter for event bit 04.
A0CE DEFB $00 Counter for event bit 05.
A0CF DEFB $00 Counter for event bit 06.
A0D0 DEFB $00 Counter for event bit 07.
