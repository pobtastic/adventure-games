B6BF: Table: Scenic Event Room Groups
One address per scenic event (05 entries; see Count_ScenicEvents). Handler_GameEvents loads this table into IX and GetTableEntry reads the address for the event index. The bytes at that address are room IDs ended by FF; see Data_ScenicEventRoomGroups.
