BAF9: Table: Saved State Addresses
Addresses of the six bytes packed into SavedStateBytes: B969, B9EC, B9FA, BA00, BA04 and BA4D. Three of them are direction bytes in Table_RoomMap, so a changed exit survives a save.
Table_SavedStateAddresses BAF9 DEFW $B969 State byte 00 at B969.
BAFB DEFW $B9EC State byte 01 at B9EC.
BAFD DEFW $B9FA State byte 02 at B9FA.
BAFF DEFW Data_SavedRoomByte State byte 03 at BA00.
BB01 DEFW Data_SavedRoomList State byte 04 at BA04.
BB03 DEFW Data_SavedRoomList2 State byte 05 at BA4D.
