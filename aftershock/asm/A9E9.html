A9E9: Action: Call Script
Runs the script addressed by the operand, then returns to the instruction after this one.
When the condition succeeded, run the operand script and come back to the next instruction.
Action_CallScript A9E9 JP NZ,Handler_RunScript_9 Leave this action alone.
A9EC LD L,(IX+$01) The script named by the operand.
A9EF LD H,(IX+$02)
A9F2 INC IX Come back to the next action afterwards.
A9F4 INC IX
A9F6 INC IX
A9F8 PUSH IX
A9FA PUSH HL Copy the called script address from HL into IX.
A9FB POP IX
A9FD JP Handler_RunScript_12 Jump to Handler_RunScript_12.
