A924: Condition: Parser Succeeds
Calls the parser check indexed in JumpTable_ParserChecks and succeeds when it returns with the carry clear.
Stores A at ScriptParserResult.
Input
IX Pointer to the script entry (opcode, check index)
Output
F The zero flag is set when the check succeeds
The operand selects a parser check from JumpTable_ParserChecks.
