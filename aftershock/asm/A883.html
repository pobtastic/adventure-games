A883: Condition: Flag Is Set
Succeeds when the flag bit operand is set in Flags_GameStates.
Output
F The zero flag is set when the bit is set
The flag test reports a clear bit, so invert it. The condition succeeds when the flag operand is set.
Condition_FlagIsSet A883 LD A,(IX+$01) The operand selects the flag.
