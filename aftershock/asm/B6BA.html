B6BA: Table: Scenic Event Items
One item ID per scenic event (05 entries; see Count_ScenicEvents). These IDs are scenic-event slots in Table_ItemLocations / Table_InitialItemLocations: Table_ItemDescriptions has no description string for them (the pointer is 0000), so they have no display name in the item map. Handler_GameEvents passes each ID to ItemLocator to find the room that slot currently occupies, and Handler_ScenicEvents tests the same IDs with ValidateItemPresent.
Table_ScenicEventItems B6BA DEFB $2E Event 00 uses item ID 2E.
B6BB DEFB $2F Event 01 uses item ID 2F.
B6BC DEFB $81 Event 02 uses item ID 81.
B6BD DEFB $82 Event 03 uses item ID 82.
B6BE DEFB $83 Event 04 uses item ID 83.
