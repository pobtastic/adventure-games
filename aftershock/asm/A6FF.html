A6FF: Handler: Run Script
Used by the routines at Handler_GameEvents, Handler_ScenicEvents, Handler_DispatchVerb and ChangeRoom.
Executes the bytecode at IX.
Each instruction is a condition from JumpTable_ScriptConditions followed by an action from JumpTable_ScriptActions. A condition that fails skips its action.
FE selects OR for the next condition and FF selects AND.
FF ends the instruction and starts another one.
Input
IX Pointer to the script bytecode
