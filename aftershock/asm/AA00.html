AA00: Action: Return From Script
Restores the script pointer saved by Action_CallScript.
When the condition succeeded, resume the script that Action_CallScript saved.
Action_ReturnFromScript AA00 JP NZ,Handler_RunScript_11 Jump to Handler_RunScript_11 if the condition failed.
AA03 POP IX Restore the saved script pointer from the stack.
AA05 JP Handler_RunScript_12 Jump to Handler_RunScript_12.
