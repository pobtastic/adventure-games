A280: Handler: Process Game Events
Used by the routine at GameStart.
Counts down the turn-based events in Flag_TurnBasedEventState and, when a counter reaches zero, runs the handler from JumpTable_TurnEvents.
Then relocates any scenic event that is not already in the current room, picking the new room from the group at Table_ScenicEventRoomGroups.
First process the turn-based events (if any are active).

Eight turn-based events share the flag byte.
