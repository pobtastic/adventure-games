A0D4: Saved State Bytes
The 06 bytes copied to and from the addresses in Table_SavedStateAddresses while saving and loading. The count is Count_SavedStateBytes.
SavedStateBytes A0D4 DEFB $00 Saved state byte 00.

A0D6 DEFB $00 Saved state byte 02.
A0D7 DEFB $00 Saved state byte 03.
A0D8 DEFB $00 Saved state byte 04.
