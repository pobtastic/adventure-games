9E2F: Pause Loop
Used by the routine at Action_Pause.
Pauses a given number of HALT loops.
Input
B Number of HALT commands to use
Pause_Loop 9E2F HALT Wait for the next interrupt (HALT).
9E30 DJNZ Pause_Loop Decrease the pause counter and loop back to Pause_Loop until the wait is over.
9E32 RET Return.
