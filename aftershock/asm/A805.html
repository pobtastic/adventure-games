A805: Script Result
ScriptMatchedItem holds the item ID found by Condition_GroupItemDiffers. An operand of FF makes Handler_RunScript_15 substitute it. ScriptParserResult holds the value returned by the latest parser check.
ScriptMatchedItem A805 DEFB $00 Matched item ID.
ScriptParserResult A806 DEFB $00 Parser result.
