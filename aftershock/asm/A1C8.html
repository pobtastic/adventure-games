A1C8: Test Flag
Used by the routines at Condition_FlagIsSet, Condition_FlagIsClear, ChangeRoom and GameStart.
Tests one bit of the flags at Flags_GameStates.
Input
A Bit index
Output
F The zero flag is set when the bit is clear
A The flag byte merged with the bit mask
TestFlag A1C8 PUSH HL Stash HL on the stack.
A1C9 LD HL,$A088 Use the game state flags at Flags_GameStates.
A1CC CALL BuildFlagMask Call BuildFlagMask to find the flag byte and the mask for this flag.
A1CF AND (HL) Test the flag; the zero flag is set when it is clear.
A1D0 POP HL Restore HL from the stack.
A1D1 RET Return.
