One bit for each entry in Table_RoomsWithImages. Handler_RoomExits sets the bit after the picture has been shown so the same room does not draw it again.

One bit per turn-based event. Handler_GameEvents counts a bit down while it is set, and the script actions Action_StartTurnEvent and Action_StopTurnEvent change the bits.

One counter byte for each bit in Flags_TurnEvents. Handler_GameEvents decreases the counter for every active event, and Action_SetTurnCounter stores a new count.
