Game Status Buffer
Address Length Description
5B00 1
Print Left Margin Column
Remembers the left-margin column for PrintMessage newline (1D) and sub-message (1F) handling.
5B01 1
Location Id
Current location. BASIC writes this before JumpTable_LocationGraphicSetup.
5BA0 2
Parser List Pointer
Copy of NSPPC kept while walking a BASIC list.
5BA2 2
Parser Work Pointer
Pointer into the work buffer at PrimaryWorkBuffer or SecondaryWorkBuffer.
5BA4 1
Parser Match Length
Characters required to accept a vocabulary match.
5BA5 1
Parser Word Index
Index of the matched word, returned to BASIC.
5BA7 2
Token Start Pointer
Pointer to the current token in InputBuffer.
5BA9 2
Next Token Pointer
Pointer to the next token in InputBuffer.
5BAB 1
Parser Token Character
First character of the current token.
5BAC 1
Parser Token Delimiter
Character that ended the current token.
5BAD 1
Parser Entry Count
Number of entries to scan in the current BASIC list.
5BAE 63
Input Buffer
Line buffer filled by InputLine. Holds up to 3E characters plus a trailing 0D written on ENTER.
5BF5 1
Print Attribute
Attribute byte written by PrintCharacter unless bit 1 of PrintState_Flags is set.
5BF6 1
Print Flags
Bit 0 selects XOR vs copy, bit 1 skips attributes, bit 2 selects OR vs XOR.
5BF7 1
Print Column
Print column (00-1F), paired with PrintState_Row as BC.
5BF8 1
Print Row
Print row (00-17), paired with PrintState_Column as BC.
5BF9 1
Print Character
Character code plotted by PrintCharacter.
5BFA 1
Input Cursor Index
Index of the cursor in InputBuffer.
5BFB 1
Input Line Length
Length of the current input line.
5BFC 1
Input Previous Key
Last KSTATE value, for edge detection.
5BFD 1
Input Dirty Flag
Set when the line has changed since the last redraw.
5BFE 1
Input Saved Length
Length saved by Caps Shift + 1.
