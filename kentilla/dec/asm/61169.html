61169: Print Message
Used by the routines at CallSubMessage and SubMessageSelect.
Walks a message script pointed to by HL. Most bytes are literal character codes passed to ClipAndPrintCharacter; values below 32 are control codes:
Code Action
0-23 Set row, then column (also PrintLeftMarginColumn)
24 Set attribute at PrintState
25 Set flags at PrintState_Flags
26 End of script (return)
27 Repeat current character
28 Fill a box of spaces
29 New line from PrintLeftMarginColumn
30 Add to column; advance row
31 Call sub-script via CallSubMessage
Dispatch the next script byte to a control handler, or print it as a literal character.
PrintMessage 61169 LD A,(HL) Fetch the next script byte.
61170 INC HL
Codes 0-23 set the print row and column.
61171 CP 24 Jump to PrintMessage_SetPosition if A is less than 24.
61173 JR C,PrintMessage_SetPosition
Code 24 sets the print attribute.
61175 JR Z,PrintMessage_SetAttribute Jump to PrintMessage_SetAttribute if A is 24.
Code 26 ends the script.
61177 CP 26 Compare A with 26.
61179 RET Z Return if this is the end-of-script code.
Code 25 sets the print flags.
61180 JR C,PrintMessage_SetFlags Jump to PrintMessage_SetFlags if A is less than 26.
Code 27 repeats the current character.
61182 CP 28 Jump to PrintMessage_Repeat if A is less than 28.
61184 JR C,PrintMessage_Repeat
Code 28 fills a box of spaces.
61186 JR Z,PrintMessage_FillBox Jump to PrintMessage_FillBox if A is 28.
Code 29 starts a new line from the left margin.
61188 CP 30 Jump to PrintMessage_NewLine if A is less than 30.
61190 JR C,PrintMessage_NewLine
Code 30 adds to the column, then advances the row.
61192 JR Z,PrintMessage_AddColumn Jump to PrintMessage_AddColumn if A is 30.
Code 31 calls a location-art sub-script.
61194 CP 31 Jump to CallSubMessage if A is 31.
61196 JP Z,CallSubMessage
