61670: Submit Input Line
Used by the routine at InputLine.
Reached from InputLine_Enter when Enter is pressed. Clears the input rows, adjusts the lower screen via ScrollAdjust, prints a > prompt, echoes InputBuffer through PrintCharacter, then returns via ScrollAdjust. Token walks and vocabulary lookup are separate jump-table entries (AdvanceInputPointer, SearchVocabulary_Commands and neighbours).
