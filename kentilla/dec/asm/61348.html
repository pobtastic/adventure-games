61348: Sub-Message Select
Used by the routine at CallSubMessage.
Picks one of the small graphic scripts at LocationGraphicScripts and jumps into PrintMessage. Ids 0-5 cover the fragments used while drawing location art.
SubMessageSelect 61348 CP 1 Jump to SubMessageSelect_DigitPunctuation if the id is 0.
61350 JR C,SubMessageSelect_DigitPunctuation
61352 JR Z,SubMessageSelect_Punctuation Jump to SubMessageSelect_Punctuation if the id is 1.
61354 CP 2 Jump to SubMessageSelect_AlternateCharset if the id is 2.
61356 JR Z,SubMessageSelect_AlternateCharset
61358 CP 4 Jump to SubMessageSelect_DualGlyph if the id is 3.
61360 JR C,SubMessageSelect_DualGlyph
61362 JR Z,SubMessageSelect_TripleGlyph Jump to SubMessageSelect_TripleGlyph if the id is 4.
61364 CP 6 Jump to SubMessageSelect_GlyphStrip if the id is 5.
61366 JR C,SubMessageSelect_GlyphStrip
61368 RET Return.
