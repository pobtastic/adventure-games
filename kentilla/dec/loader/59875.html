59875: Loader Checksum Data
Stored checksum word, running-total workspace, timing-switch flag, and the two five-byte timing-parameter tables used by Switch_Timing.
LoaderChecksumData 59875 DEFW 0 Checksum scan pointer.
Additive total compared with *Expected_Checksum before each tape sample.
Running_Checksum_Total 59877 DEFW 0 Running checksum total.
Compared with *Running_Checksum_Total before each tape sample.
Expected_Checksum 59879 DEFW 61373 Expected checksum.
Toggled by Switch_Timing to choose which timing table to copy next.
Timing_Switch_Flag 59881 DEFB 0 Timing switch flag.
Copied into Sample_Tape when *Timing_Switch_Flag is zero.
Timing_Parameters_First 59882 DEFB 22,176,178,203,176 Timing parameter set 0.
Copied into Sample_Tape when *Timing_Switch_Flag is non-zero.
Timing_Parameters_Second 59887 DEFB 21,194,196,216,194 Timing parameter set 1.
