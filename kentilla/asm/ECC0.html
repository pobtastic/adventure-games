ECC0: Input Line Redraw
Used by the routine at InputLine.
Repaint the buffered characters at row 16 via PrintCharacter, pad with two spaces, then fall into InputLine_DrawCursor to draw the cursor.
InputLine_Redraw ECC0 LD HL,$5BAE Point at the buffer and reset print state for row 16.

ECCF LD A,$16

ECD4 LD A,($5BFB) Jump to InputLine_Redraw_Pad if the line is empty.

ECDA LD B,A
InputLine_Redraw_Loop ECDB LD A,(HL) Print each buffered character through PrintCharacter.
ECDC LD ($5BF9),A

ECE2 INC HL
ECE3 DJNZ InputLine_Redraw_Loop
