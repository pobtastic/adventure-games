EA8D: Print Character
Used by the routines at InputLine, InputLine_Redraw, ClipAndPrintCharacter and SubmitInputLine.
Plots one character glyph into the display file. Callers set up PrintState first.
PrintCharacter EA8D PUSH AF Stash the flags, counters, screen pointer and glyph pointer on the stack.
EA8E PUSH BC
EA8F PUSH DE
EA90 PUSH HL
Pick the plot opcode written into PrintCharacter_PlotOpcode: AE (XOR (HL)) or B6 (OR (HL)) from bit 2 of the flags.
EA91 LD A,($5BF6) Fetch *PrintState_Flags and test bit 2.
EA94 BIT 2,A
EA96 LD A,$AE Prefer AE (XOR) unless bit 2 was set.
EA98 JR Z,PrintCharacter_SetPlotOpcode
EA9A LD A,$B6 A=B6 (OR).
PrintCharacter_SetPlotOpcode EA9C LD ($EAF1),A Patch that opcode into PrintCharacter_PlotOpcode.
Point HL at the 8-byte glyph. Codes below 8F use CHARS; 90 and above were meant to index UDG, but the unconditional jump at PrintCharacter_ForceChars always takes the CHARS path.
EA9F LD A,($5BF9) Fetch *PrintState_Character and compare it with 8F.

PrintCharacter_ForceChars EAA4 JR PrintCharacter_CharsGlyph Always take the CHARS path at PrintCharacter_CharsGlyph.
