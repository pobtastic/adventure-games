EEF1: Print Message
Used by the routines at CallSubMessage and SubMessageSelect.
Walks a message script pointed to by HL. Most bytes are literal character codes passed to ClipAndPrintCharacter; values below 20 are control codes:
Code Action
00-17 Set row, then column (also PrintLeftMarginColumn)
18 Set attribute at PrintState
19 Set flags at PrintState_Flags
1A End of script (return)
1B Repeat current character
1C Fill a box of spaces
1D New line from PrintLeftMarginColumn
1E Add to column; advance row
1F Call sub-script via CallSubMessage
Dispatch the next script byte to a control handler, or print it as a literal character.
PrintMessage EEF1 LD A,(HL) Fetch the next script byte.
EEF2 INC HL
Codes 00-17 set the print row and column.
EEF3 CP $18 Jump to PrintMessage_SetPosition if A is less than 18.
EEF5 JR C,PrintMessage_SetPosition
Code 18 sets the print attribute.
EEF7 JR Z,PrintMessage_SetAttribute Jump to PrintMessage_SetAttribute if A is 18.
Code 1A ends the script.
EEF9 CP $1A Compare A with 1A.
EEFB RET Z Return if this is the end-of-script code.
Code 19 sets the print flags.
EEFC JR C,PrintMessage_SetFlags Jump to PrintMessage_SetFlags if A is less than 1A.
Code 1B repeats the current character.
EEFE CP $1C Jump to PrintMessage_Repeat if A is less than 1C.
EF00 JR C,PrintMessage_Repeat
Code 1C fills a box of spaces.
EF02 JR Z,PrintMessage_FillBox Jump to PrintMessage_FillBox if A is 1C.
Code 1D starts a new line from the left margin.
EF04 CP $1E Jump to PrintMessage_NewLine if A is less than 1E.
EF06 JR C,PrintMessage_NewLine
Code 1E adds to the column, then advances the row.
EF08 JR Z,PrintMessage_AddColumn Jump to PrintMessage_AddColumn if A is 1E.
Code 1F calls a location-art sub-script.
EF0A CP $1F Jump to CallSubMessage if A is 1F.
EF0C JP Z,CallSubMessage
Literal character: store it and print via ClipAndPrintCharacter.
EF0F LD ($5BF9),A Store the character in *PrintState_Character and print it.
EF12 CALL ClipAndPrintCharacter
EF15 JR PrintMessage Jump to PrintMessage.
