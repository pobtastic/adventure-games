F14C: Scan Input Spaces
Used by the routine at JumpTable.
Jump-table target JumpTable_ScanInputSpaces: walk InputBuffer until a quote or a character below space. On quote, seed InputBuffer_TokenStart / InputBuffer_NextToken, call AdvanceInputPointer, then set BC=0000. The early return for a character below 20 leaves BC unchanged.
ScanInputSpaces F14C LD DE,$5BAE Point DE at InputBuffer.
F14F LD B,D
ScanInputSpaces_Loop F150 LD A,(DE) Fetch the next character and compare it with space.
F151 INC DE
F152 CP $20
F154 RET C Return if the next character is below space.
F155 CP $22 Keep scanning until a quote.
F157 JR NZ,ScanInputSpaces_Loop
F159 LD ($5BA7),DE Seed both token pointers, call AdvanceInputPointer, and set BC=0000.
F15D LD ($5BA9),DE
F161 CALL AdvanceInputPointer
F164 LD BC,$0000
F167 RET Return.
