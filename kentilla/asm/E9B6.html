E9B6: Loaded Machine Code
The final tape block loads 164A bytes here through FFFF. It overwrites the Micromega 1.1 loader that lived here during loading. BASIC reaches the support code through the jump table at JumpTable.
Documented so far: JumpTable (jump table, commands and all verb handlers), InputLine (input line), vocabulary lookup / tables, PrintCharacter (character printing) and PrintMessage (message scripts). Location-graphic dispatch, work-buffer contents and charset buffers are left for later PRs.
