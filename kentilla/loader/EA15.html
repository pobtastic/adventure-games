EA15: Patch Timing
Used by the routine at Switch_Timing.
Copies the selected five timing parameters into the sampler at Sample_Tape.
Input
HL Address of the five-byte timing parameter set
Patch_Timing EA15 LD A,(HL) Write the first parameter to *EB51.
EA16 LD ($EB51),A
EA19 INC HL Advance HL.
EA1A LD A,(HL) Write the second parameter to *EB0F.
EA1B LD ($EB0F),A
EA1E INC HL Advance HL.
EA1F LD A,(HL) Write the third parameter to *EB30.
EA20 LD ($EB30),A
EA23 INC HL Advance HL.
EA24 LD A,(HL) Write the fourth parameter to *EB38.
EA25 LD ($EB38),A
EA28 INC HL Advance HL.
EA29 LD A,(HL) Write the fifth parameter to *EB3D.
EA2A LD ($EB3D),A
EA2D RET Return.
