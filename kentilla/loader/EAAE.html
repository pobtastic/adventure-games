EAAE: Sample Tape
Used by the routine at Control_Loading.
Custom turbo sampler. Before sampling it compares the loader's additive checksum in *Running_Checksum_Total against the expected value in *Expected_Checksum.
Input
IX Destination address for the block
DE Block length
A Expected flag byte; carry set to load, reset to verify
Output
F Carry is set on success
Refuse to load if the self-check total is wrong.
Sample_Tape EAAE PUSH DE Stash DE and AF on the stack.
EAAF PUSH AF
EAB0 LD HL,($E9E7) Jump to START if *Expected_Checksum does not equal *Running_Checksum_Total.
EAB3 LD DE,($E9E5)
EAB7 SCF
EAB8 CCF
EAB9 SBC HL,DE
EABB JP NZ,$0000
EABE POP AF Restore AF and DE from the stack.
EABF POP DE
Preserve the flag byte and blank the border.

EAC1 EX AF,AF'
EAC2 DEC D
EAC3 DI Disable interrupts.
EAC4 LD A,$00 Set the border to black via port FE.
EAC6 OUT ($FE),A
EAC8 LD HL,$053F Set the initial timing budget in HL to 053F.
Seed the EAR/border state in C from the current EAR bit.
EACB IN A,($FE) Read the EAR port.
EACD RRA Rotate the EAR bit into bit 0 of A.
EACE AND %00100000 Keep only the EAR bit.
EAD0 OR %00000010 Set the blue border bit.
EAD2 LD C,A Copy the EAR/border state into C and set the zero flag.
EAD3 CP A
Wait for the pilot tone.
Sample_Tape_WaitPilot EAD4 RET NZ Return if the zero flag is reset (BREAK was pressed).
Listen for a pair of edges that look like the pilot.
Sample_Tape_PilotPair EAD5 CALL Sample_Edge_Wait Jump back to Sample_Tape_WaitPilot if Sample_Edge_Wait resets the carry flag.
EAD8 JR NC,Sample_Tape_WaitPilot
EADA LD HL,$0415 Set the leader timing budget in HL to 0415.
Exhaust the leader timing budget while edges continue to arrive.
Sample_Tape_LeaderDelay EADD DJNZ Sample_Tape_LeaderDelay Decrease B and loop until it is zero.
EADF DEC HL Decrease HL.
EAE0 LD A,H Jump back to Sample_Tape_LeaderDelay if HL is non-zero.
EAE1 OR L

EAF0 LD A,$A6 Jump back to Sample_Tape_PilotPair if B is at least A6.
EAF2 CP B
EAF3 JR NC,Sample_Tape_PilotPair

EAF6 JR NZ,Sample_Tape_PilotPulse

EAFA CALL Sample_Edge_Wait Jump back to Sample_Tape_WaitPilot if Sample_Edge_Wait resets the carry flag.
EAFD JR NC,Sample_Tape_WaitPilot

EB00 CP $D4

EB04 CALL Sample_Edge_Wait Call Sample_Edge_Wait and return if the carry flag is reset.
EB07 RET NC
