5CFC: Load Tape Block
Used by the routine at Load_Stage_Two.
Custom edge sampler used by the bootstrap. It still calls the ROM edge routines LD-EDGE-1 / LD-EDGE-2, but with Micromega timing thresholds rather than the standard ROM pilot. On success it returns through Restore_Border; tape errors from Load_Stage_Two jump to Load_Tape_Block_PrintError, which prints "TAPE LOADING ERROR" via Restore_Border_PrintLoop.
Input
IX Destination address for the block
DE Block length
A Expected flag byte; carry set to load, reset to verify
Output
F Carry is set on success; A' holds the preserved flag byte
Preserve the flag byte and install the post-load return at Restore_Border.
