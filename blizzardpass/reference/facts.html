The Sinsister Crypt
With pictures switched on, room 1E ("A Sinister Foreboding Crypt") is described by its short text, which is stored tokenised at 784C. That text reads "you are in a sinsister foreboding crypt", with "sinister" misspelled. The typo is in the original game, so the bytes are left exactly as they are, but the caption on the room's picture at Picture_ForebodingCrypt corrects the spelling to "Sinister". The long description in bank 6, used when pictures are switched off, doesn't use the word.

Dedicated To Hawkwind
The game's welcome text, stored tokenised at the start of TokenisedLocations, dedicates Blizzard Pass to the band Hawkwind. See also MobyGames.
Leftover Source Code
When the game was saved, part of Alan Cox's assembler source was still in memory. At AssemblerSource_Leftovers you can read lines 1090 to 1140 of it, including CP (HL) and JR Z,found. The Cutting Room Floor lists the same fragments.
A Ghost In The Inventory
The copy at PrepareGame moves 0100 bytes from InitialObjects, running on past the source leftovers into RoomRecords and the start of the picture at Picture_FreezingBlizzard. Its FD byte lands on object slot F4, so the "drop everything" routine at DropEverything treats that slot as carried and writes the current room to 5EBE, a slot no object uses.
Back In AberMUD
Alan Cox later reused Blizzard Pass as a zone in AberMUD, where the scenario credits that section "(C)1988 Alan Cox". Sources: MobyGames trivia, Wikipedia. In the AberMUD version you freeze to death within about twenty moves unless you find warmth (AberMUD news).
128K Only
Blizzard Pass needs a 128K Spectrum, and its loader uses OUT 32765,23 to page memory before loading. It was sold with H.A.R.D. by Tynesoft in 1986 and on Tynesoft's 128 – 4 Pack in 1987. Source: Spectrum Computing.
Bank 7 Unused
The loader pages bank 7 only so 128 BASIC can load the game. The game is copied into banks 6, 3 and 0 and never selects bank 7 again. The top of bank 0 still holds 128 BASIC leftovers from BasicResidue, including a fragment of its character set from FF58.
ADVENTURE
The nine bytes at Signature spell ADVENTURE, but the key routine and the random condition overwrite them and use the first byte as scratch space.
Red To Red
System message 81CF holds the riddle "red to red, wave to wave, thus pass away from cave to cave. Seek the sorcerors doom, near the once wet place, not a room. Seek the hidden way in the dungeons. He is across the pit of fire bridged by a sceptre. Aranus last wiza...." It breaks off mid-word, and "sorcerors" is spelled that way in the game.
Leftovers
UnusedActionTail is an unused, older version of the end of the action table, the redraw routine and the glyph buffer, and UnusedObjectCopy is an unused copy of the first 3C bytes of the object list.
