B748: Initial Object Locations Padding
Seven more FC bytes after the last of the A0 objects at InitialObjects. The copy at 603B takes them to ObjectLocations too, but no object uses them. DropEverything, which visits FE slots, finds nothing carried here, and the script runner at RunScripts only loads one when a counter test or a message number is A0 or more, and those routines ignore the location. In practice the padding is unused.
InitialObjects_Padding B748 DEFB $FC,$FC,$FC,$FC,$FC,$FC,$FC
