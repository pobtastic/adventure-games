5F16: Character Row Address
Used by the routines at HomeRow, ScrollWindow and ClearLowerRows.
Turns a character row in A into the display address of that row.
Output
DE Display address of character row A
RowAddress 5F16 LD L,A Double the row number.
5F17 LD H,$00
5F19 ADD HL,HL
5F1A LD DE,$5BD0 Add the screen-row table at ScreenRows.
5F1D ADD HL,DE
5F1E JP $2AF0 Enter DE_DE_1 at 2AF0 to load the row address into DE.
