B74F: Assembler Source Leftovers
Part of the game's assembler source that happened to be in memory when the data was saved. Each line is a two-byte line number, a length byte, the text and 0D. The copy at 603B takes 0100 bytes from InitialObjects, so it runs on through these bytes and into the first 10 bytes of RoomRecords. None of these bytes is FD, so DropEverything, which visits FE slots, never treats them as carried. It does treat slot F4 as carried, because the FD at Picture_FreezingBlizzard lands there, so DropEverything also writes the current room to 5EBE, a slot no object uses, when dropping everything.
