B798: Per-Room Picture Records
One record per room, each ended by FF. This first FF is the record for room 0, the opening message, which has no picture. FindPictureRecord counts the terminators to find a room, so the records run on past Picture_IcePalaceHall into RAM bank 0, where rooms 60 to 6B live at Picture_IcyThroneHall onwards. RoomHasChanged walks the same table. Inside a record (see PictureRecord and DispatchShape), a byte below EE is a shape number followed by its column and row. F9 draws another room's record, F8 names an object whose shape is drawn only while it is here, FD changes one colour to another in the ink and paper, FC paints a run of attributes, FB brightens the picture, FA mirrors it left to right, and FE reflects its left half onto the right.
