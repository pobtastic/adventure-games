6A16: Action: Set Object Location
Writes a new location for the object. A value of 1 for an object numbered 46 or higher is stored as zero. If the new location is the current room, the room is marked changed.
SetObjectLocation 6A16 CALL ObjectAddress Point at the object's location. C is the new one.
