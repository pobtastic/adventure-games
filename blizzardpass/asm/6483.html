6483: Plot Glyph
Used by the routine at PlotCharacter.
Draws character A at the print position, using the ROM font. The eight bytes are shifted into whichever pixel column the cursor occupies inside its display byte, then ORed into the screen.
The ROM character set lives at Character set. Subtracting 0100 makes the character code times 8 land on its glyph.
