6AAD: Action: Take Object Off
Stops wearing the object and carries it instead. Message 1C says you are not wearing it.
Input
B Object number
C Object location
RemoveWorn 6AAD CALL ObjectAddress Point at the object's location.
6AB0 LD A,($5D8A) Not worn continues to the refusal.
6AB3 CP C
6AB4 JR Z,RemoveWorn_Do
6AB6 LD A,$1C Message 1C: you are not wearing it.
6AB8 JP GetObject_Refuse
RemoveWorn_Do 6ABB LD A,($5D89) The carried id replaces the worn location, and the carried count rises.
6ABE LD (HL),A
6ABF LD HL,$5D8C
6AC2 INC (HL)
6AC3 RET Return.
