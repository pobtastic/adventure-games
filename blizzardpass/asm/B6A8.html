B6A8: Initial Object Locations
Where each object starts, one byte per object: a room number, or FC when the object is nowhere. 603B copies these bytes to ObjectLocations at the start of a game. Room descriptions (61EC) look at objects 00 to 96, stopping at ObjectTotal, and the inventory (ListCarried) looks at all A0 of them. Every object from 96 on starts nowhere.
