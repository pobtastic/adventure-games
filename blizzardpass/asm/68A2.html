68A2: Action: Move To Object
Makes the object's location the current room.
Input
B Object number
MoveToObject 68A2 LD C,B Point at object B's location byte.
68A3 LD B,$00
68A5 LD HL,$5DCA
68A8 ADD HL,BC
68A9 LD A,(HL) That location becomes the current room.
68AA LD ($5D87),A
68AD JP RoomHasChanged Jump to RoomHasChanged so the new room is described.
