FFDC: Start Game
The last loader block. It loads 0100 bytes over the command buffer and falls into the game. The snapshot is paused on the call into GameLoop.
The 0100 bytes are a headerless block, flagged by the carry.
StartGame FFDC LD IX,$5B00 Load into CommandBuffer.
FFE0 LD DE,$0100
FFE3 LD A,$00
FFE5 SCF
FFE6 CALL $0556 Call LD-BYTES.
GameEntry FFE9 CALL GameLoop Call GameLoop to run the adventure.
