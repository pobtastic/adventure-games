73F1: Address Pixel Row
Used by the routines at ShapeIfPresent_Mirror, DrawFixedShift_Pixels, PixelRow_LeftRun, HorizontalRun_RightRun and VerticalRun_Mirror.
Turns a pixel row in B into a display address via the character-row table.
Input
B Pixel row
C Column
Output
HL Display address
PixelRow 73F1 LD A,B Call RowWord with the pixel row.
73F2 CALL RowWord
73F5 PUSH DE Copy the screen address to HL (using the stack).
73F6 POP HL
73F7 LD B,$00 Add the column.
73F9 ADD HL,BC
73FA RET Return.
