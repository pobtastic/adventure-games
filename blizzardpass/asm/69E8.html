69E8: Action: Force Verb And Noun
Replaces the command with verb B and noun A, and forgets that a script line has already matched so the new command can be tried.
Input
A Noun
B Verb
ForceCommand 69E8 LD ($5B80),A A becomes the noun and B becomes the verb.
69EB LD A,B
69EC LD ($5B7F),A
69EF XOR A Forget that a script line has already matched, so the new command can be tried.
69F0 LD ($5B79),A
69F3 RET Return.
