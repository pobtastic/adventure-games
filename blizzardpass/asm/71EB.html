71EB: Fetch Parameter Byte
Used by the routines at PictureAddress and PaintShape.
Returns the next parameter byte while Parameter_Count is non-zero, otherwise the next shape byte from Saved_Shape_Pointer.
Output
A The byte
Fetch a byte from the parameter block, or the next shape byte.
FetchParameterByte 71EB LD A,($5B9E) Jump to FetchParameterByte_Stream if Parameter_Count is 00.
71EE OR A
71EF JR Z,FetchParameterByte_Stream
71F1 DEC A Count one fewer in Parameter_Count.
71F2 LD ($5B9E),A
71F5 LD HL,$5B9F Point HL at Parameter_Byte.
71F8 LD A,(HL) Fetch that byte.
71F9 RET Return.
Fetch the next shape byte after the parameters.
FetchParameterByte_Stream 71FA LD HL,($5BCC) Fetch Saved_Shape_Pointer.
71FD LD A,(HL) Fetch that byte.
71FE RET Return.
