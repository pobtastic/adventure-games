68B0: Action: Get
Picks the object up. It must be in the room, not already carried, and not worn. The carried id is written into the object's own location slot and the carried count increases.
GetObject 68B0 LD A,($5D89) Already carried is message 15.
68B3 CP C
68B4 JR NZ,GetObject_Worn
68B6 LD A,$15
This entry point is used by the routines at DropObject, WearObject and RemoveWorn.
