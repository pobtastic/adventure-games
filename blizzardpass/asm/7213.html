7213: Draw Shape When Object Is Here
Used by the routine at DispatchShape.
Opcode F8 names an object. The following shape is drawn only when that object is in the current room, and the object id is planted in the low address byte (5F11) of LD (Continuation),A at 5F10. When the object is absent that byte is cleared again.
