7213: Draw Shape When Object Is Here
Used by the routine at DispatchShape.
Opcode F8 names an object. The following shape is drawn only when that object is in the current room. The object id is written over the low address byte (5F11) of LD (*Continuation),A at 5F10, so the next unrecognised line zeros CommandBuffer plus that id. Those addresses are the command buffer and the bytes after it, not object state. When the object is absent the operand is set to 00. RoomHasChanged compares PicturedObject, which this routine never writes.
