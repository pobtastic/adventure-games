5ECB: Game Loop
Used by the routines at OfferAnotherGame, Restored and StartGame.
Runs the adventure. It prepares a new game, describes the room, runs the location scripts, draws the picture, then reads a command and obeys it. A ROM error returns with the stack at ErrorStack.
Install the word at ErrorStack as the ROM error handler and give the game its own stack.
GameLoop 5ECB LD HL,$6B41 Store ErrorStack in ERR_SP.
5ECE LD ($5C3D),HL
5ED1 LD SP,$5D84 SP=StackTop.
Start in the first room with an empty inventory.
5ED4 CALL PrepareGame Call PrepareGame to prepare a new game.
5ED7 XOR A Clear *PictureDrawn.
5ED8 LD ($6185),A
5EDB CALL DescribeLocation Call DescribeLocation to describe the first room.
This entry point is used by the routines at ObeyCommand and RefuseCommand.
Run the high-priority scripts, and describe the room again if they moved the player.
