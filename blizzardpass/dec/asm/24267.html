24267: Game Loop
Used by the routines at OfferAnotherGame, Restored and StartGame.
Runs the adventure. It prepares a new game, describes the room, runs the location scripts, draws the picture, then reads a command and obeys it. A ROM error returns with the stack at ErrorStack.
Install the word at ErrorStack as the ROM error handler and give the game its own stack.
