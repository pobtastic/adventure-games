24664: Run High-Priority Scripts
Used by the routines at GameLoop and ObeyCommand.
Clears the first 'J' marker when both marker slots hold 74, then runs the script table at PriorityScripts.
The loader subtracted 3 from the address written below, so the snapshot clears 24069 rather than 24072.
RunPriorityScripts 24664 LD A,(24069) Object slot 59 must hold 'J' (74).

24671 LD A,(24072) Object slot 62 must hold 'J' as well.
24674 CP 74
24676 JR NZ,RunPriorityScripts_Run
24678 XOR A Clear slot 59. A fresh game has 252 in slot 62, so this does not fire.
