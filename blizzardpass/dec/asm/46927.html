46927: Assembler Source Leftovers
Part of the game's assembler source that happened to be in memory when the data was saved. Each line is a two-byte line number, a length byte, the text and 13. The copy at 24635 takes 256 bytes from InitialObjects, so it runs on through these bytes and into the first 16 bytes of RoomRecords. None of these bytes is 253, so DropEverything, which visits 254 slots, never treats them as carried. It does treat slot 244 as carried, because the 253 at Picture_FreezingBlizzard lands there, so DropEverything also writes the current room to 24254, a slot no object uses, when dropping everything.
