27071: Action: Swap Objects
Exchanges the locations of the object in the parameter and the object addressed by A, then marks the room changed.
Input
A Second object
B First object
C First object location
SwapObjects 27071 CALL ObjectAddress Point at the first object's location.
27074 PUSH HL
27075 LD B,A Point at the second object.
27076 CALL ObjectAddress
27079 LD A,(HL) Exchange the two location bytes.
27080 LD (HL),C
27081 POP HL
27082 LD (HL),A
27083 JR RoomHasChanged Jump to RoomHasChanged once the two locations have been exchanged.
