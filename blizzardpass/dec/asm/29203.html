29203: Draw Shape When Object Is Here
Used by the routine at DispatchShape.
Opcode 248 names an object. The following shape is drawn only when that object is in the current room, and the object id is planted in the low address byte (24337) of LD (Continuation),A at 24336. When the object is absent that byte is cleared again.
