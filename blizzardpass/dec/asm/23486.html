23486: Shift Flags
How the current tile is shifted and merged. Bit 0 selects the second tile page. Bits 2-3 are the combine mode: 4 OR, 8 AND, 12 XOR. Bits 4-5 choose the shift: 16 left, 32 right, 48 logical right. Bit 6 adds an extra left rotate. Bit 1 is set when a run count follows.
