39508: Command Scripts
Bytecode for the player's verbs: movement that the exit table did not handle, GET, DROP, WEAR and the rest. RunScripts runs it after a command has been parsed. Each line is a verb and a noun, then conditions while bit 7 of the next byte is clear, then actions while bit 7 is set. Verb or noun 126 matches any word. 127 ends the table. Action bit 6 stops the runner after that action.
