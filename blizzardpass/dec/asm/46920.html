46920: Initial Object Locations Padding
Seven more 252 bytes after the last of the 160 objects at InitialObjects. The copy at 24635 takes them to ObjectLocations too, but no object uses them. DropEverything, which visits 254 slots, finds nothing carried here, and the script runner at RunScripts only loads one when a counter test or a message number is 160 or more, and those routines ignore the location. In practice the padding is unused.
