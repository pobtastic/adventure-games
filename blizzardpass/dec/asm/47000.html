47000: Per-Room Picture Records
One record per room, each ended by 255. This first 255 is the record for room 0, the opening message, which has no picture. FindPictureRecord counts the terminators to find a room, so the records run on past Picture_IcePalaceHall into RAM bank 0, where rooms 96 to 107 live at Picture_IcyThroneHall onwards. RoomHasChanged walks the same table. Inside a record (see PictureRecord and DispatchShape), a byte below 238 is a shape number followed by its column and row. 249 draws another room's record, 248 names an object whose shape is drawn only while it is here, 253 changes one colour to another in the ink and paper, 252 paints a run of attributes, 251 brightens the picture, 250 mirrors it left to right, and 254 reflects its left half onto the right.
