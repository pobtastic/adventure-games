46760: Initial Object Locations
Where each object starts, one byte per object: a room number, or 252 when the object is nowhere. 24635 copies these bytes to ObjectLocations at the start of a game. Room descriptions (25068) look at objects 0 to 150, stopping at ObjectTotal, and the inventory (ListCarried) looks at all 160 of them. Every object from 150 on starts nowhere.
