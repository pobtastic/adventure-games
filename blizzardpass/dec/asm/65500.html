65500: Start Game
The last loader block. It loads 256 bytes over the command buffer and falls into the game. The snapshot is paused on the call into GameLoop.
The 256 bytes are a headerless block, flagged by the carry.
StartGame 65500 LD IX,23296 Load into CommandBuffer.
65504 LD DE,256
65507 LD A,0
65509 SCF
65510 CALL 1366 Call LD-BYTES.
GameEntry 65513 CALL GameLoop Call GameLoop to run the adventure.
