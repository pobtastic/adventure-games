B9C8 74
Table: Item Locations
Workspace filled from Default_Table_ItemLocations by the routine at GameStart. Object locations occupy the 4A bytes at Table_ItemLocations. The current room is *CurrentRoom. Pointers to the message, exit and handler tables follow.
BA2C 1
Flags: Display State
Bit 0 is set when the long room description was just shown, so Handler_DisplayRoom waits for a key before listing exits and objects.
BA30 2

Handler_DisplayRoom tests and sets the bit for the current room. The bit number is the room's place in E806.
BA36 1
Flags: Turn-Based Event States
Holds a single byte, where each bit relates to a turn-based event as follows:
Bit Relating To
00 Wood nymph
01 Spider
02 Slime monster
03 Demons
04 Wizard
When the bit is set, this starts a turn counter (see Counter_WoodNymph).
BA37 8
Turn-Based Event Counters
One countdown per bit of *Flag_TurnBasedEventState. Handler_TurnBasedEvents decrements a set counter each turn and runs the handler from Pointer_TurnBasedEvents_Jump when it hits zero.
BA3F 1
Flag: Princess Following
Only bit 0 is used. When it is set, Princess Mara ("The Princess,Mara", the first byte of Table_FollowingItems) follows the player from room to room. MovePlayerToRoom moves the item for each set bit into the room the player just entered. Bits 1-7 are never set.
BA40 8
Table: Following Items
Each bit of *Flag_PrincessFollowing makes the item at the same position here follow the player when the room changes. Default bit 0 holds "The Princess,Mara" (Princess Mara).
BA48 13
Table: Scenic Event Locations
Where each of the 0D scenic events is (the count is at Count_ScenicEvents).
Byte Meaning
00 Not in play
Other The room the event is in
Populated by GameStart. See Handler_TurnBasedEvents, Handler_ScenicEvents and MovePlayerToRoom for usage.

Pointers to the direction names, in the order north, south, east, west, up and down.

4A pointers to the object messages. Indexed with the count stored at *Count_Items.

Table: Room Descriptions
One pointer per room. Room 00 and room 01 are unused. The starting room is 05, The Great Valley.

2A pointers to the noun phrases the parser matches.
E934 462
Table: Room Exits
Six direction bytes for each room, in the order used by GetRoomPointer: north, south, east, west, up, down. 00 means no exit. Some of these bytes are rewritten when a door opens or an event moves the player.

Addresses zeroed by the routine at GameStart before the game starts.

Starting places for the items. GameStart copies this table to Table_ItemLocations at the start of every game.
