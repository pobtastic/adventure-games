48831: Clear Room Image
Flood the picture's attribute area with the given colour.
Input
A Attribute byte value
ClearRoomImage 48831 LD BC,512 Start at the attribute file and count 512 bytes.
48834 LD HL,22528
48837 LD E,A Keep that attribute colour.
ClearRoomImage_Loop 48838 LD (HL),E Write that colour through the picture attributes.
48839 INC HL
48840 DEC BC
48841 LD A,B
48842 OR C
48843 JR NZ,ClearRoomImage_Loop Jump back to ClearRoomImage_Loop until the picture area is filled.
48845 RET Return.
