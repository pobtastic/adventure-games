50223: Move Player To Room
Used by the routines at Handler_InjuryCheck and Action_Blow.
Moves the player to a new room. Before updating the current room, it updates all scenic events that were in the old room to be in the new room (so they follow the player). It then moves each item whose bit is set in Flag_PrincessFollowing into the new room. Only bit 0, Princess Mara, is ever set.
Input
A Destination room ID
Store the destination room ID and prepare to update scenic events.

Loop through all scenic events and move any that are in the current room to the destination room (so they follow the player).
