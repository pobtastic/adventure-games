BE5E: Print Room Graphic
Used by the routine at Print_RoomImage.
Unpack a room picture into the display, drawing it in the paper colour.
Input
IX Pointer to room image data
Print_RoomGraphic BE5E CALL SwitchToNormalScreenOutput Call SwitchToNormalScreenOutput to select the screen channel.
BE61 LD BC,$1821 Set the cursor to row 18, column 21.
BE64 CALL $0DD9 Call CL_SET.
Draw the picture in the paper colour.
BE67 LD HL,$5C8F Take the current attribute from *ATTR_T.
BE6A LD A,(HL) Fetch the attribute byte.
BE6B AND $38 Keep only the PAPER bits.
BE6D RRA Move the PAPER bits into the INK bits.
BE6E RRA
BE6F RRA
BE70 LD B,A Keep that ink colour.
BE71 LD A,(HL) Fetch the attribute byte again.
BE72 AND $F8 Keep everything except the old INK bits.
BE74 OR B Combine the two values.
BE75 LD (HL),A Write the result back to *ATTR_T.
BE76 LD BC,$0200 Count 0200 picture bytes.
Print_RoomGraphic_Loop BE79 PUSH BC Keep the byte counter safe.

BE82 INC IX

BE8B LD A,(IX+$00) Read the next picture byte and advance through the picture.
BE8E INC IX
BE90 JR Print_RoomGraphic_StoreByte Jump to Print_RoomGraphic_StoreByte to store the picture byte.

BE94 DJNZ Print_RoomGraphic_NextByte Repeat from Print_RoomGraphic_NextByte until the eight bits of this control byte are used.
BE96 LD DE,$BB45 Take the finished scanline (BB45).
BE99 CALL $0B03 Call PO_FETCH.
