BF55: Handler: Update Object Location
Used by the routines at Handler_DestroyItem, Handler_UpdateItemForTheCurrentRoom, Handler_RemoveItemFromPlay, TransformItem, TakeItem, Validate_Take_MarasBody, Validate_Take_Log, Action_Drop and Action_Row.
Write a new location for an object, or for a scenic-event room.
Bit 7 selects the scenic-room list instead of the object table.
UpdateObjectLocation BF55 BIT 7,B Jump to UpdateObjectLocation_Objects for an ordinary object.
BF57 JR Z,UpdateObjectLocation_Objects
BF59 RES 7,B Clear that bit and use the scenic list (Table_ScenicEventLocations).
BF5B LD HL,$BA48
BF5E JR UpdateObjectLocation_Write Jump to UpdateObjectLocation_Write to write the location.
UpdateObjectLocation_Objects BF60 LD HL,$B9C8 Look up the object locations (Table_ItemLocations).
UpdateObjectLocation_Write BF63 LD D,$00 Write the new location.
BF65 LD E,B
BF66 ADD HL,DE
BF67 LD (HL),C
BF68 RET Return.
