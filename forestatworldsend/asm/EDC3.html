EDC3: Action: Help
Explain how badly hurt the player is, if at all.
Action_Help EDC3 CALL Parser_ValidateNoDirectObject Return if the words after the verb are not valid for this command.
EDC6 RET C
EDC7 LD A,$48 Jump to Action_Help_Next if object 48 (the injury) is not here.
EDC9 CALL IsObjectInCurrentRoom
EDCC JR NZ,Action_Help_Next
EDCE LD A,$8A Jump to Action_Help_Next when object 8A (the wood nymph) is here.
EDD0 CALL IsObjectInCurrentRoom
EDD3 JR Z,Action_Help_Next
EDD5 LD A,$8A Call GetObjectLocation to fetch where the wood nymph is.
EDD7 CALL GetObjectLocation
EDDA AND A Jump to Action_Help_Next when the injury is not in play.
EDDB JR Z,Action_Help_Next
EDDD LD HL,$DC4F Print "Help is on the way." to say help is on the way.
EDE0 JR Action_Help_Reply
Action_Help_Next EDE2 LD HL,$DC35 The player is not hurt, so say "Work it out for yourself.".
Action_Help_Reply EDE5 JP PrintResponse Return through the shared reply at PrintResponse.
