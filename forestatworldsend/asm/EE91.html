EE91: Action: Quit
Ask whether to abandon the game and, if so, offer to save it.
Action_Quit EE91 CALL Parser_ValidateNoDirectObject Return if the words after the verb are not valid for this command.
EE94 RET C
EE95 LD HL,$BC85 Print "Want to save the game? Y/N.".
EE98 CALL PrintStringAndANewline
Action_Quit_Loop EE9B CALL GetUserInput Call GetUserInput to wait for a keypress.
EE9E CP $4E Jump to Action_Quit_Next if "N" was pressed.
EEA0 JR Z,Action_Quit_Next
EEA2 CP $59 Jump back to Action_Quit_Loop if "Y" was not pressed.
EEA4 JR NZ,Action_Quit_Loop
EEA6 CALL SaveGame Call SaveGame to save the game to tape.
Action_Quit_Next EEA9 LD HL,$EB29 Switch GameOver_WantAnother onto the stack.
EEAC EX (SP),HL
EEAD RET Return.
