EDE8: Action: Inventory
List everything the player is carrying.
Action_Inventory EDE8 CALL Parser_ValidateNoDirectObject Return if the words after the verb are not valid for this command.
EDEB RET C
EDEC LD A,($BA68) Jump back to Response_YoureNotCarryingAnything when the number of objects carried is zero.
EDEF AND A
EDF0 JP Z,Response_YoureNotCarryingAnything
EDF3 CALL ClearScreen Call ClearScreen to clear the screen.
EDF6 CALL SetScreenPosition Call SetScreenPosition to move the cursor to the text line stored at BB40.
EDF9 LD HL,$BD1F Print "You are carrying:-".
EDFC CALL PrintStringAndANewline
EDFF LD A,$01 Call PrintObjects to list what is being carried.
EE01 CALL PrintObjects
EE04 RET Return.
