E6BC: Table: Object Words
The vocabulary number (Table_Vocabulary) of each of the 2A objects the player can name (the count is at Count_Objects). The position of a word in this list is its object number, which also indexes Table_ObjectNounPhrases for its name in "I can't see ... here." replies.
Reached through Pointer_ObjectList: Parser_FindPhrase counts the object words in a command, and Parser_MatchVocabulary looks each named object up here.
