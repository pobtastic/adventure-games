BA3F: Flag: Princess Following
Only bit 0 is used. When it is set, Princess Mara ("The Princess,Mara", the first byte of Table_FollowingItems) follows the player from room to room. MovePlayerToRoom moves the item for each set bit into the room the player just entered. Bits 1-7 are never set.
