5B00: Tape Loader
Load the picture, the room graphics and the game from tape, then start.
Load the picture.
TapeLoader 5B00 LD IX,$4000 Load 1B00 bytes of the picture to 4000.
5B04 LD DE,$1B00
5B07 CALL TapeLoading Call TapeLoading to load the picture.
Load the room graphics.
5B0A LD IX,$61A8 Load 581D bytes of the room graphics to Image_TheGreatValley.
5B0E LD DE,$581D
5B11 CALL TapeLoading Call TapeLoading to load the room graphics.
Load the game, then fall into the loader.
5B14 LD IX,$B9C5 Load 41C8 bytes of the game to GameEntryPoint.
5B18 LD DE,$41C8
