ECB6: Handler: Injury Check
Used by the routines at Action_Down, Action_Climb, Action_Enter and GameStart.
Refuse the move while the player is badly hurt. Otherwise change rooms and arm the local dangers.
Handler_InjuryCheck ECB6 LD C,A Call IsObjectInCurrentRoom to test whether the injury is in this room. Jump to Handler_InjuryCheck_Next when the player is not too badly hurt.
ECB7 LD A,$48
ECB9 CALL IsObjectInCurrentRoom
ECBC JR NZ,Handler_InjuryCheck_Next
ECBE LD HL,$DB38 Print "You can't move. You are too badly injured.".
ECC1 CALL PrintStringAndANewline
ECC4 RET Return.
Handler_InjuryCheck_Next ECC5 LD A,C Call MovePlayerToRoom to move the player into that room.
ECC6 CALL MovePlayerToRoom
ECC9 LD E,$00 Call Handler_DisplayRoom to describe the current room.
ECCB CALL Handler_DisplayRoom
ECCE LD A,$41 Jump to Handler_InjuryCheck_SlimeMonster if object 41 (the giant spider) is not here.
ECD0 CALL IsObjectInCurrentRoom
ECD3 JR NZ,Handler_InjuryCheck_SlimeMonster
ECD5 LD HL,$BA36 Arm the giant spider for six turns.
ECD8 SET 1,(HL)
ECDA LD A,$06
ECDC LD ($BA38),A
Handler_InjuryCheck_SlimeMonster ECDF LD A,$1E Jump to Handler_InjuryCheck_Demons if object 1E (the slime monster) is not here.
ECE1 CALL IsObjectInCurrentRoom
ECE4 JR NZ,Handler_InjuryCheck_Demons
ECE6 LD HL,$BA36 Arm the slime monster for six turns.
ECE9 SET 2,(HL)
ECEB LD A,$06
ECED LD ($BA39),A
Handler_InjuryCheck_Demons ECF0 LD A,$29 Jump to Handler_InjuryCheck_Zarn if object 29 (the demons) is not here.
ECF2 CALL IsObjectInCurrentRoom
ECF5 JR NZ,Handler_InjuryCheck_Zarn
ECF7 LD HL,$BA36 Arm the demons for six turns.
ECFA SET 3,(HL)
ECFC LD A,$06
ECFE LD ($BA3A),A
