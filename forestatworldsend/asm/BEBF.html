BEBF: Clear Room Image
Flood the picture's attribute area with the given colour.
Input
A Attribute byte value
ClearRoomImage BEBF LD BC,$0200 Start at the attribute file and count 0200 bytes.
BEC2 LD HL,$5800
BEC5 LD E,A Keep that attribute colour.
ClearRoomImage_Loop BEC6 LD (HL),E Write that colour through the picture attributes.
BEC7 INC HL
BEC8 DEC BC
BEC9 LD A,B
BECA OR C
BECB JR NZ,ClearRoomImage_Loop Jump back to ClearRoomImage_Loop until the picture area is filled.
BECD RET Return.
