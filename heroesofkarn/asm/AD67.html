AD67: Clear Room Image
Copy one attribute byte across the 0200 cells of the picture. Nothing calls this routine.
Input
A Attribute byte value
ClearRoomImage AD67 LD BC,$0200 Set a counter in BC of 0200 bytes.
AD6A LD HL,$5800 Point HL at the attribute buffer (5800).
AD6D LD E,A Copy the attribute byte into E.
ClearRoomImage_Loop AD6E LD (HL),E Write the byte to the attribute buffer.
AD6F INC HL Advance HL to the next cell.
AD70 DEC BC Step the picture-cell count down.
AD71 LD A,B See whether any picture cells remain.
AD72 OR C
AD73 JR NZ,ClearRoomImage_Loop Branch to ClearRoomImage_Loop while cells remain.
AD75 RET Return.
