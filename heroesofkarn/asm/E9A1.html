E9A1: Game Loop
Used by the routine at GameStart.
One turn: run events, read a command, and dispatch its verb.
GameLoop E9A1 CALL ProcessGameEvents Call ProcessGameEvents to advance the turn-based events.
E9A4 XOR A Clear the turn scratch flag (08 marks an attack).
E9A5 LD ($AE78),A
E9A8 CALL HandlerUserInput Call HandlerUserInput to read the next command.
E9AB CALL ParserProcessItem Call ParserProcessItem to apply the command to the item.
E9AE JR C,GameLoop Start the next turn without running the verb if a named item isn't here (carry set by ParserProcessItem).
E9B0 CALL HandlerMatchVerb Call HandlerMatchVerb to run the verb.
E9B3 JR GameLoop Take another turn at GameLoop.
