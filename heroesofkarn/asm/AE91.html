AE91: Flag: Following Heroes
Each set bit makes the matching item in Table_FollowingItems follow the player when the room changes (Handler_SetCurrentRoom). Bits 0-3 default to N/A (Beren), N/A (Istar), N/A (Haldir) and N/A (Khadim). Bits 4-7 are never set. Handler_ChangeRoom also reads this byte when checking the ruined cottage.
