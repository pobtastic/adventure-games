AD54: Colour Room Image
Used by the routine at Print_RoomImage.
Copy the picture's attribute bytes onto the screen.
Input
IX Pointer to the room attribute data
ColourRoomImage AD54 LD DE,$5800 Point DE at the attribute file.
AD57 PUSH IX Copy the attribute pointer from IX into HL.
AD59 POP HL
AD5A LD BC,$0200 Use 0200 as the count in BC.
AD5D LDIR Copy the counted bytes from HL to DE.
AD5F RET Return.
