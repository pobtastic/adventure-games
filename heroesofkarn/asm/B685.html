B685: Parser: Validate Input Tokens
Check the words after the verb, and ask for a rephrase when none of them is a known item. Nothing calls this routine.
Output
F The carry flag is set when the command is malformed
The first token is the verb, so read the second token.
Parser_ValidateInputTokens B685 LD A,($AF2F) Read the second word token into A.
B688 CP $FF Compare the token with the terminator.
B68A RET Z Return if there is no second token.
There is a second token, so count the known items.
B68B CALL ParserCountItemReferences Call ParserCountItemReferences to count how the command refers to the item.
B68E RET NZ Return if a known item was named.
The words are not known items.
B68F CALL Messaging_PleaseRephraseThat_Newline Call Messaging_PleaseRephraseThat_Newline to ask the player to rephrase.
B692 SCF Mark the command as malformed.
B693 RET Return.
