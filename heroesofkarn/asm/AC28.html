AC28: Print String

Print an FF-terminated string.
Input
HL Pointer to string to be printed
PrintString AC28 CALL SwitchToNormalScreenOutput Call SwitchToNormalScreenOutput to switch to the normal screen output.
Just keep looping and printing the fetched character until the termination byte is reached (FF).
PrintString_Loop AC2B LD A,(HL) Load a character from the string pointer into A.
AC2C INC HL Move the string pointer to the next character.
AC2D CP $FF Return if the string termination character (FF) has been reached.
AC2F RET Z
AC30 CALL PrintCharacter Call PrintCharacter to print the character.
AC33 JR PrintString_Loop Print the next character.
