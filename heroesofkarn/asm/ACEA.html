ACEA: Print Input Prompt
Used by the routine at HandlerUserInput.
Print the input prompt.
PrintInputPrompt ACEA LD HL,$5080 Point at the prompt graphic in the display file.
ACED LD DE,$0100 Set the increment in DE for the next screen line.
ACF0 LD B,$08 Scan the eight pixel rows of the prompt cell.
ACF2 XOR A
PrintInputPrompt_Loop ACF3 OR (HL) Collect the pixels of this row of the prompt cell.
ACF4 ADD HL,DE Move down one line.
ACF5 DJNZ PrintInputPrompt_Loop Repeat for all eight pixel rows, so A is non-zero if anything is already drawn in the cell.
ACF7 OR A Jump to PrintPrompt if A is zero.
ACF8 JR Z,PrintPrompt
Force a newline to be "printed".
ACFA LD A,$0D Use the ENTER key code.
ACFC CALL PrintCharacter Call PrintCharacter to print the character.
PrintPrompt ACFF LD HL,$AF4D Print "> ".
AD02 CALL PrintString
AD05 RET Return.
