5B00: Tape Loader
Load the screen, the room pictures and the game. The last block falls straight into the tape loading routine.
Load the first block: the loading screen.
TapeLoader 5B00 LD IX,$4000 Load 1B00 bytes of the loading screen to 4000 with flag byte D7.
5B04 LD DE,$1B00
5B07 LD A,$D7
5B09 CALL TapeLoading
Load the second block: the room pictures.
5B0C LD IX,$61A8 Load 4A2C bytes of picture data to Image_TheField with flag byte 0A.
5B10 LD DE,$4A2C
5B13 LD A,$0A
5B15 CALL TapeLoading
Load the third block: the game. Execution falls into TapeLoading.
5B18 LD IX,$ABD4 Load 5235 bytes of the game to GameEntryPoint with flag byte 2B.
5B1C LD DE,$5235
5B1F LD A,$2B
