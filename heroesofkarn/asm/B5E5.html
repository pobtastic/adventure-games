B5E5: Handler: Set Scenic Event As Triggered
Mark the scenic event in A as already fired. The scenic-event count is zero, so nothing calls this routine.
Input
A Scenic event id
ScenicEventTriggered B5E5 LD B,A Copy the scenic event id into B.
B5E6 LD C,$FF Use FF for C so the event is not repeated.
B5E8 CALL SetItemRoom Call SetItemRoom to store the item's room.
B5EB RET Return.
