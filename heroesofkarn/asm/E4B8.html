E4B8: Table: Object Words
The vocabulary number (Table_Vocabulary) of each of the 48 objects the player can name (the count is at Count_Objects). The position of a word in this list is its object number, which also indexes Table_ItemGrouping for the items it may mean.
Reached through Pointer_ObjectList: ParserCountItemReferences counts the object words in a command, and ParserProcessItem looks each named object up here.
