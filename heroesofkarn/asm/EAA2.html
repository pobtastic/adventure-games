EAA2: Pause, Print String And Scroll
Pause, print the string at HL, and scroll. The phrase handlers call this entry.
PausePrintAndScroll EAA2 CALL PausePrintStringAndScroll Call PausePrintStringAndScroll to pause, print the string and scroll.
