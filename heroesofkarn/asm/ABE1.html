ABE1: Get User Input
Used by the routines at SaveGame, HandlerUserInput, HandlerAskToPlayAgain, Action_Load, Action_Quit and HandlerTheEdgeOfTheSea.
Wait until the player presses a key, then return that key.
Output
A The keypress value
GetUserInput ABE1 LD A,($5C3B) A=*FLAGS.
ABE4 BIT 5,A Jump back to GetUserInput until a new key is pressed.
ABE6 JR Z,GetUserInput
ABE8 RES 5,A Reset the "new key has been pressed" flag in A.
ABEA LD ($5C3B),A Write it back to *FLAGS.
Fetch the keypress.
ABED LD A,($5C08) A=*LAST_K.
ABF0 RET Return.
