46598: Find Active Scenic Event
Walk the scenic-event list at HL and return the index of the first one that matches.
FindActiveScenicEvent 46598 LD B,0 Start the index at 0.
46600 JR FindActiveScenicEvent_Next Check the first scenic event at FindActiveScenicEvent_Next.
FindActiveScenicEvent_Loop 46602 INC B Advance the index in B.
46603 INC HL Advance HL to the next event.
FindActiveScenicEvent_Next 46604 CALL CheckActiveScenicEvents Call CheckActiveScenicEvents to check the scenic events.
46607 JR Z,FindActiveScenicEvent_Loop Branch to FindActiveScenicEvent_Loop to count each listed item that is here, until the end of the list.
46609 LD A,B Copy the index into A.
46610 RET Return.
