46630: Is Item In Current Room
Compare the item's room with the room the player is in.
Input
A Item id
Output
F The zero flag is set when the item is in the current room
IsItemInCurrentRoom 46630 CALL GetItemRoom Call GetItemRoom to read which room holds the item.
46633 LD HL,44749 Point HL at the current room.
46636 CP (HL) See whether the item is in this room.
46637 RET Return.
