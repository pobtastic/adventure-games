23329: Tape Loading
Used by the routine at TapeLoader.
Pull one tape block into the address and length set up by the caller.
Tape loading routine.
TapeLoading 23329 SCF Set the carry flag to indicate "loading".
23330 INC D This resets the Z flag (D cannot hold +255.)
23331 EX AF,AF' The A register holds +0 for a header and +255 for a block of data. The carry flag is reset for verifying and set for loading.
23332 DEC D Put back D to its original value.
23333 DI Disable interrupts while the tape loads, as the start of LD_BYTES would.
23334 LD A,15 Set the border to WHITE.
23336 OUT (254),A

23347 RRC A Move the border colour into the low three bits.
23349 RRC A
23351 RRC A

23355 LD A,127 See whether SPACE is pressed.
