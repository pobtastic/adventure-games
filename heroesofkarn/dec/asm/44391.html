44391: Clear Room Image
Copy one attribute byte across the 512 cells of the picture. Nothing calls this routine.
Input
A Attribute byte value
ClearRoomImage 44391 LD BC,512 Set a counter in BC of 512 bytes.
44394 LD HL,22528 Point HL at the attribute buffer (22528).
44397 LD E,A Copy the attribute byte into E.
ClearRoomImage_Loop 44398 LD (HL),E Write the byte to the attribute buffer.
44399 INC HL Advance HL to the next cell.
44400 DEC BC Step the picture-cell count down.
44401 LD A,B See whether any picture cells remain.
44402 OR C
44403 JR NZ,ClearRoomImage_Loop Branch to ClearRoomImage_Loop while cells remain.
44405 RET Return.
