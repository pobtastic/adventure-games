46611: Transform Item
Used by the routines at ChangeRoom, Take_Flower, Take_CopperKey, Take_GoldKey, Take_JewelledKey, Take_Water, Take_Acid, Take_Oil, Take_Pillow, Handler_ReportTheKill, Drop_CopperKey, Drop_GoldKey, Drop_JewelledKey, Throw_MirrorToAnton, Throw_HoneyToBear, Kiss_Chest, Kiss_Coffin, Kiss_ClamWithCrowbar, Throw_MoneyToGuard, Use_Bottle, Wave_Flute, Wave_Mandolin, Play_SerpentWithSongbird, Play_HydraWithSpear, Play_VampireWithCross, Play_KnightWithAcid, Play_DragonWithSword, Play_WitchWithWater, Kill_Chest, Oil_Plant, Oil_Ashes, Drink_Water, Take_Songbird, Play_BatWithFalcon, Wave_Lyre and Play_PirateWithDagger.
Transforms one item into another by destroying the "from" item and creating the "to" item in the same location. Rather than use item properties, the game just has separate objects that don't exist until an action is performed.
Input
B From item ID (the item to be destroyed)
C To item ID (the item to be created)
Get the location of the "from" item so the "to" item can be created in the same place.
TransformItem 46611 LD A,B Copy the "from" item ID into A.
46612 CALL GetItemRoom Call GetItemRoom to get the room ID where the "from" item is located (returns in A).
46615 PUSH BC Remember the items and the room while the first is removed.
46616 PUSH AF
Destroy the "from" item by setting its location to 0 (inactive).
46617 LD C,0 Set the room ID to 0 to deactivate the "from" item.
46619 CALL SetItemRoom Call SetItemRoom to update the "from" item's location to 0.
46622 POP AF Restore AF, BC from the stack.
46623 POP BC
Create the "to" item at the same location where the "from" item was.
46624 LD B,C Copy the "to" item ID into B.
46625 LD C,A Copy the location (from A) into C.
46626 CALL SetItemRoom Call SetItemRoom to create the "to" item at the stored location.
46629 RET Return.
