Game Status Buffer
Address Length Description
AD76 135
Table: Item Locations
One byte per item. The value is the room the item is in, 00 when the item is inactive, and the inventory room when the player is carrying it.
AE76 1
Flags: Room Change
Bit 0 and bit 1 gate the special move out of room 37.
AE77 1
Flag: Beach Dug
Bit 0 is set once the player has dug on the beach in room 3C.
AE78 1
Flag: Turn Scratch
Cleared at the start of every pass round the game loop.
AE79 1
Room: Pour Return
Holds the room ID to restore after pouring.
AE7E 2
Table: Already Seen Room Images
Corresponds to whether the player has already seen the image for the following rooms:
Bit Room ID Room Name
00 03 In the Field
01 0E The Monastery
02 1C The King's Chamber
03 27 The Oil Room
04 28 The Acid Room
05 3D The Sea Cavern
06 12 Within the Long Barrow
07 2B The Hall of the Black Knight
Bit Room ID Room Name
00 29 The Treasury
01 13 At the Edge of the Sea
02 N/A N/A
03 N/A N/A
04 N/A N/A
05 N/A N/A
06 N/A N/A
07 N/A N/A
HandlerDisplayRoomImage tests and sets the bit for the current room. The bit number is the room's place in Table_RoomsWithImages.
AE88 1
Flags: Turn-Based Event States
Holds a single byte, where each bit relates to a turn-based event. GameEventsProcessor decrements the matching counter in Counter_Unused_0 and, when a counter reaches zero, would call through Pointer_TurnBasedEvents_Jump. The shipped image leaves Pointer_TurnBasedEvents_Jump as 00 and never sets these bits.
AE89 8
Turn-Based Event Counters
One countdown per bit of *Flag_TurnBasedEventState. GameEventsProcessor decrements a set counter each turn. The shipped image never arms any of them.
AE91 1
Flag: Following Heroes
Each set bit makes the matching item in Table_FollowingItems follow the player when the room changes (Handler_SetCurrentRoom). Bits 0-3 default to N/A (Beren), N/A (Istar), N/A (Haldir) and N/A (Khadim). Bits 4-7 are never set. Handler_ChangeRoom also reads this byte when checking the ruined cottage.
AE92 8
Table: Following Items
Each bit of *Flag_FollowingHeroes makes the item at the same position here follow the player when the room changes.
AE9A 1
Number Of Items In The Players Inventory
The number of items the player is currently holding.
AE9B 50
Load/ Save Buffer
Save Game copies the configurable-exit bytes here before writing the tape block. The buffer is 32 bytes, ending at the current room.
AECD 1
Current Room ID
The room the player starts the game in is room 03: In the Field.
AECE 2
Score
BCD score. Add To Score accumulates into this word.

Command Buffer
The line the player is typing. The input handler clears all 32 bytes.

User Input: Word Tokens

AF39 4
Four Letter Buffer
The four-character word UserInput_Enter is matching. The routine fills it with ASCII spaces (20) and then copies up to 04 characters of the next command word into it.

Graphics: Room Image Row
